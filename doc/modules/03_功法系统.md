# 功法系统设计文档

## 模块概述

本模块定义游戏中的功法系统，包括功法的获取、学习、品级、合成等机制。

## 核心内容

### 功法分类

- 攻击类功法
- 防御类功法
- 辅助类功法
- 特殊类功法

### 功法等级

功法分为天地玄黄4个大等级，等级越高，基础属性加成越多。

| 等级 | 描述 | 判定机制提升 |
|------|------|--------------|
| 黄级 | 初级功法 | - |
| 玄级 | 中级功法 | 命中率 +5%，暴击率 +3% |
| 地级 | 高级功法 | 命中率 +10%，暴击率 +6%，格挡率 +5% |
| 天级 | 顶级功法 | 命中率 +15%，暴击率 +10%，格挡率 +10%，抗暴击 +10% |

### 功法品级

每个等级分为上中下3个品级，品级越高，伤害系数和属性加成越强。

| 等级 | 品级 | 伤害系数加成 | 属性加成 |
|------|------|--------------|----------|
| 黄级 | 下品 | 100% | 基础值 |
| 黄级 | 中品 | 110% | 基础值 × 1.1 |
| 黄级 | 上品 | 125% | 基础值 × 1.25 |
| 玄级 | 下品 | 130% | 基础值 × 1.3 |
| 玄级 | 中品 | 145% | 基础值 × 1.45 |
| 玄级 | 上品 | 165% | 基础值 × 1.65 |
| 地级 | 下品 | 175% | 基础值 × 1.75 |
| 地级 | 中品 | 195% | 基础值 × 1.95 |
| 地级 | 上品 | 220% | 基础值 × 2.2 |
| 天级 | 下品 | 235% | 基础值 × 2.35 |
| 天级 | 中品 | 260% | 基础值 × 2.6 |
| 天级 | 上品 | 300% | 基础值 × 3.0 |

### 功法攻击类型

根据战斗系统，功法有三种攻击类型：

| 攻击类型 | 描述 | 适用功法 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 单体伤害技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

### 功法伤害机制

功法伤害是在基础伤害计算的基础上，再乘以功法伤害系数。

#### 单段伤害功法

```
功法每段伤害 = 基础伤害 × 功法伤害系数 × 品级加成系数
```

#### 多段伤害功法

每段伤害单独计算命中、暴击、格挡。

**触发逻辑**：
- 第一段伤害必定触发
- 后续每段伤害有独立的触发概率
- 一旦某一段未触发，后面所有段都不会继续触发

### 功法获取途径

| 途径 | 描述 | 可获得品级 |
|------|------|------------|
| 历练 | 日常挂机、任务获得 | 黄级下品-黄级上品 |
| 挑战 | 副本、BOSS挑战 | 黄级中品-地级下品 |
| 活动 | 限时活动、节日活动 | 玄级下品-天级下品 |
| 合成 | 3个相同品级合成更高一品 | 任意品级 |

### 功法合成

3个相同等级、相同品级的功法可以合成更高一品的功法。

**合成规则**：
```
3个黄级下品 → 1个黄级中品
3个黄级中品 → 1个黄级上品
3个黄级上品 → 1个玄级下品
...以此类推
```

**合成限制**：
- 天级上品无法再合成（已最高级）
- 合成后原功法消失
- 合成必定成功，无失败风险

### 功法示例 - 七星剑阵

| 属性 | 描述 |
|------|------|
| 名称 | 七星剑阵 |
| 攻击类型 | 单体攻击 |
| 伤害段数 | 7段 |
| 命中类型 | 每段单独命中判定 |

#### 伤害段数详情

| 段数 | 伤害系数 | 触发概率 | 说明 |
|------|----------|----------|------|
| 第1剑 | 30% | 100% | 必定触发 |
| 第2剑 | 40% | 100% | 必定触发 |
| 第3剑 | 50% | 70% | 中断则后面不触发 |
| 第4剑 | 60% | 70% | 中断则后面不触发 |
| 第5剑 | 70% | 70% | 中断则后面不触发 |
| 第6剑 | 80% | 70% | 中断则后面不触发 |
| 第7剑 | 100% | 70% | 中断则后面不触发 |

#### 七星剑阵品级提升效果

| 品级 | 基础伤害系数 | 暴击率加成 |
|------|--------------|------------|
| 黄级下品 | 100% | 0% |
| 黄级中品 | 110% | 0% |
| 黄级上品 | 125% | 0% |
| 玄级下品 | 130% | +3% |
| 玄级中品 | 145% | +3% |
| 玄级上品 | 165% | +3% |
| 地级下品 | 175% | +6% |
| 地级中品 | 195% | +6% |
| 地级上品 | 220% | +6% |
| 天级下品 | 235% | +10% |
| 天级中品 | 260% | +10% |
| 天级上品 | 300% | +10% |

#### 七星剑阵完整伤害计算

```
总伤害 = 0
触发了前一段 = true

for (段数 from 1 to 7) {
    if (触发了前一段) {
        if (段数 >= 3) {
            if (random(100) >= 70) {
                break  // 中断，后面不再触发
            }
        }
        
        // 计算本段伤害
        基础伤害 = max(攻击力 - 防御力, 1)
        功法系数 = 本段伤害系数 / 100 × 品级加成系数
        
        命中判定（加入等级判定加成）
        暴击判定（加入等级判定加成）
        格挡判定（加入等级判定加成）
        本段伤害 = 基础伤害 × 功法系数 × 暴击系数 × 格挡系数
        
        总伤害 += 本段伤害
        触发了前一段 = true
    }
}

return 总伤害
```

### 功法使用

- 每个角色可装备多个功法
- 战斗中自动选择合适的功法使用
- 可设置功法优先级

## 与其他模块的关联

- 角色系统：功法影响角色属性，角色可使用灵气淬体提升自身
- 战斗系统：战斗中使用功法技能
- 挂机系统：挂机时可修炼功法、参与历练获得功法
