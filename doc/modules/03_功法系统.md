# 功法系统设计文档

## 模块概述

本模块定义游戏中的功法系统，包括功法的获取、学习、升级、突破等机制。

## 核心内容

### 功法分类

- 攻击类功法
- 防御类功法
- 辅助类功法
- 特殊类功法

### 功法攻击类型

根据战斗系统，功法有三种攻击类型：

| 攻击类型 | 描述 | 适用功法 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 单体伤害技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

### 功法伤害机制

功法伤害是在基础伤害计算的基础上，再乘以功法伤害系数。

#### 单段伤害功法

```
功法每段伤害 = 基础伤害 × 功法伤害系数 × 多段伤害系数
```

#### 多段伤害功法

每段伤害单独计算命中、暴击、格挡。

**触发逻辑**：
- 第一段伤害必定触发
- 后续每段伤害有独立的触发概率
- 一旦某一段未触发，后面所有段都不会继续触发

### 功法示例 - 七星剑阵

| 名称 | 七星剑阵 |
|------|----------|
| 攻击类型 | 单体攻击 |
| 伤害段数 | 7段 |
| 命中类型 | 每段单独命中判定 |

#### 伤害段数详情

| 段数 | 伤害系数 | 触发概率 | 说明 |
|------|----------|----------|------|
| 第1剑 | 30% | 100% | 必定触发 |
| 第2剑 | 40% | 100% | 必定触发 |
| 第3剑 | 50% | 70% | 中断则后面不触发 |
| 第4剑 | 60% | 70% | 中断则后面不触发 |
| 第5剑 | 70% | 70% | 中断则后面不触发 |
| 第6剑 | 80% | 70% | 中断则后面不触发 |
| 第7剑 | 100% | 70% | 中断则后面不触发 |

#### 七星剑阵完整伤害计算

```
总伤害 = 0
触发了前一段 = true

for (段数 from 1 to 7) {
    if (触发了前一段) {
        if (段数 >= 3) {
            if (random(100) >= 70) {
                break  // 中断，后面不再触发
            }
        }
        
        // 计算本段伤害
        基础伤害 = max(攻击力 - 防御力, 1)
        功法系数 = 本段伤害系数 / 100  // 30% → 0.3
        
        命中判定、暴击判定、格挡判定
        本段伤害 = 基础伤害 × 功法系数 × 暴击系数 × 格挡系数
        
        总伤害 += 本段伤害
        触发了前一段 = true
    }
}

return 总伤害
```
