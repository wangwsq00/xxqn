# 功法系统设计文档

## 模块概述

本模块定义游戏中的功法系统，包括功法的获取、学习、品级、合成等机制。

## 核心内容

### 功法分类

- 攻击类功法
- 防御类功法
- 辅助类功法
- 特殊类功法

### 功法槽设置

每个角色有5个功法槽：

| 槽位 | 名称 | 说明 |
|------|------|------|
| 1号 | 功法槽1 | 玩家自定义，优先释放 |
| 2号 | 功法槽2 | 玩家自定义，次优先 |
| 3号 | 功法槽3 | 玩家自定义，第三优先 |
| 4号 | 功法槽4 | 玩家自定义，第四优先 |
| 5号 | 普通攻击 | 固定，无冷却，无视禁止施法 |

### 功法释放机制

战斗时按1-4号功法顺序自动释放，跳过无法释放的功法：

1. 检查1号功法是否可释放
2. 可释放则使用，不可则检查2号
3. 继续检查3号、4号
4. 所有功法槽都不可释放时，使用普通攻击

**无法释放的情况**：
- 功法冷却中
- 被禁止施法状态
- 功法未装备

### 功法等级体系

功法分为天地玄黄4个大等级，每个等级分为上中下3个品级。

**大等级（影响技能效果判定）**：
| 等级 | 描述 |
|------|------|
| 黄级 | 初级功法 |
| 玄级 | 中级功法 |
| 地级 | 高级功法 |
| 天级 | 顶级功法 |

**小品级（影响属性数值加成）**：
| 品级 | 相对位置 |
|------|----------|
| 下品 | 第1档 |
| 中品 | 第2档 |
| 上品 | 第3档 |

### 功法属性加成机制

属性加成以最低级（黄级下品）为基准，每升一级（含小品级和大等级）增加20%基准值。

**属性加成公式**：
```
等级索引 = (大等级索引 × 3) + 小品级索引
属性加成 = 基准值 × (1 + 等级索引 × 0.2)
```

**等级索引表**：
| 品级 | 等级索引 |
|------|----------|
| 黄级下品 | 0 |
| 黄级中品 | 1 |
| 黄级上品 | 2 |
| 玄级下品 | 3 |
| 玄级中品 | 4 |
| 玄级上品 | 5 |
| 地级下品 | 6 |
| 地级中品 | 7 |
| 地级上品 | 8 |
| 天级下品 | 9 |
| 天级中品 | 10 |
| 天级上品 | 11 |

### 功法技能效果

功法技能效果受大等级影响，不同功法的大等级变动需要单独设定。

#### 七星剑阵完整伤害计算

```
总伤害 = 0
触发了前一段 = true
必定触发段数 = 功法等级对应的必定触发段数

for (段数 from 1 to 7) {
    if (触发了前一段) {
        // 检查是否需要判定触发
        if (段数 > 必定触发段数) {
            if (random(100) >= 70) {
                break  // 中断，后面不再触发
            }
        }
        
        // 计算本段伤害
        基础伤害 = max(攻击力 - 防御力, 1)
        功法系数 = 本段伤害系数 / 100
        
        命中判定
        暴击判定
        格挡判定
        本段伤害 = 基础伤害 × 功法系数 × 暴击系数 × 格挡系数
        
        总伤害 += 本段伤害
        触发了前一段 = true
    }
}

return 总伤害
```

### 功法攻击类型

根据战斗系统，功法有三种攻击类型：

| 攻击类型 | 描述 | 适用功法 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 单体伤害技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

### 功法获取途径

| 途径 | 描述 | 可获得品级 |
|------|------|------------|
| 历练 | 日常挂机、任务获得 | 黄级下品-黄级上品 |
| 挑战 | 副本、BOSS挑战 | 黄级中品-地级下品 |
| 活动 | 限时活动、节日活动 | 玄级下品-天级下品 |
| 合成 | 3个相同品级合成更高一品 | 任意品级 |

### 功法合成

3个相同等级、相同品级的功法可以合成更高一品的功法。

**合成规则**：
```
3个黄级下品 → 1个黄级中品
3个黄级中品 → 1个黄级上品
3个黄级上品 → 1个玄级下品
...以此类推
```

**合成限制**：
- 天级上品无法再合成（已最高级）
- 合成后原功法消失
- 合成必定成功，无失败风险

### 功法使用

- 战斗前可自由设置1-4号功法槽
- 战斗中按顺序自动释放
- 每个角色可装备多个功法（但只有4个可设置为释放槽）

## 与其他模块的关联

- 角色系统：功法影响角色属性，角色可使用灵气淬体提升自身
- 战斗系统：战斗中使用功法技能
- 挂机系统：挂机时可修炼功法、参与历练获得功法
