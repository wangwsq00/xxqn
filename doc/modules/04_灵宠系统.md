# 灵宠系统设计文档

## 模块概述

本模块定义灵兽/灵宠的获取、培养、进化、功法学习和战斗协同机制。

**解锁条件**: 角色达到金丹期后开启灵宠系统

## 核心内容

### 一、灵宠基础

#### 1. 灵宠分类

**按品阶划分**:

| 品阶 | 颜色标识 | 成长潜力 | 获取难度 |
|------|---------|---------|---------|
| 凡品 | 白色 | 低 | 易获得 |
| 良品 | 绿色 | 中低 | 较易 |
| 上品 | 蓝色 | 中等 | 一般 |
| 卓品 | 紫色 | 中高 | 较难 |
| 极品 | 橙色 | 高 | 困难 |
| 仙品 | 金色 | 极高 | 极难/活动 |

**按类型划分**:

| 类型 | 特点 | 适合定位 |
|------|------|---------|
| 攻击型 | 高攻击、高暴击 | 输出辅助 |
| 防御型 | 高防御、高格挡 | 承伤辅助 |
| 敏捷型 | 高速度、高闪避 | 先手控制 |
| 辅助型 | 提供增益效果 | 团队支援 |

#### 2. 灵宠属性

灵宠拥有与角色类似的属性体系：

| 属性类型 | 属性名 | 说明 |
|---------|--------|------|
| 基础属性 | 生命值 | 灵宠血量 |
| 基础属性 | 攻击力 | 灵宠攻击 |
| 基础属性 | 防御力 | 灵宠防御 |
| 基础属性 | 速度 | 灵宠速度 |
| 高级属性 | 暴击率 | 灵宠暴击概率 |
| 高级属性 | 格挡率 | 灵宠格挡概率 |

**属性计算公式**:
```
灵宠攻击力 = 灵宠基础攻击 × (1 + 境界加成) + 灵宠装备攻击
灵宠生命值 = 灵宠基础生命 × (1 + 境界加成) + 灵宠装备生命
// 其他属性同理
```

#### 3. 灵宠境界

灵宠有自己的境界体系，与角色境界独立但相关联：

| 灵宠境界 | 解锁条件 | 说明 |
|---------|---------|------|
| 一阶（幼年期） | 初始获得 | 基础状态，可学习1-2号功法 |
| 二阶（成长期） | 灵宠等级达到20级 | 属性提升，可学习3号功法 |
| 三阶（成熟期） | 灵宠等级达到40级 | 属性大幅提升，可学习4号功法 |
| 四阶（化形期） | 灵宠达到元婴境以上 | 可化为人形，全功能解锁 |
| 五阶（飞升期） | 灵宠达到化神境以上 | 顶级形态，特殊外观 |

**灵宠境界与角色境界的关系**:
- 灵宠境界上限 = 角色当前大境界
- 例如: 角色金丹期 → 灵宠最高三阶；角色元婴期 → 灵宠最高四阶

### 二、灵宠功法系统

#### 1. 功法槽位

灵宠共有4个功法槽位：

| 槽位 | 解锁条件 | 说明 |
|------|---------|------|
| 1号槽 | 出生自带 | 第一个技能，固定不可更换 |
| 2号槽 | 出生自带 | 第二个技能，固定不可更换 |
| 3号槽 | 灵宠达到元婴境及以上 | 可从灵宠功法池中选择装配 |
| 4号槽 | 灵宠达到元婴境及以上 | 可从灵宠功法池中选择装配 |

**出生自带功法**:
- 根据灵宠品种决定1、2号槽的固定功法
- 不同品种的灵宠有不同的天生技能
- 示例:
  - 烈焰狐: 【火焰球】(单体伤害)、【烈焰护体】(防御增益)
  - 寒冰鹤: 【冰刺】(单体伤害+减速)、【寒冰领域】(范围减速)
  - 雷电豹: 【雷击】(单体高伤)、【闪电链】(连锁伤害)

**可学习功法（3、4号槽）**:
- 灵宠达到元婴境后开放
- 通过使用"灵宠功法残卷"学习新功法
- 功法残卷可通过：商城购买、活动奖励、副本掉落获得
- 已学习的功法可在3、4号槽之间自由切换装配

#### 2. 灵宠功法示例

| 功法名称 | 类型 | 效果 | 适用灵宠 |
|---------|------|------|---------|
| 啃咬 | 单体攻击 | 造成80%攻击力伤害 | 全部 |
| 扑击 | 单体攻击 | 造成120%攻击力伤害 | 攻击型 |
| 铁壁 | 增益 | 为自身提供20%防御buff | 防御型 |
| 加速 | 增益 | 为自身提供15%速度buff | 敏捷型 |
| 治愈之光 | 治疗 | 为主角恢复10%生命值 | 辅助型 |
| 威慑 | 控制有概率使敌人眩晕1秒 | 全部 |

### 三、灵宠战斗机制

#### 1. 战斗位置

**单人战斗时**:
```
我方阵容（最多5个位置）:
位置4 ┌─────┐
位置2 │ 灵宠 │ ← 灵宠固定在2号位
位置1 │ 角色 │ ← 角色在1号位（主目标）
位置3 │      │
位置5 │      │
```

- 灵宠出战时占据**2号位**
- 角色（玩家）始终在**1号位**
- 灵宠自动释放功法，无需手动操作
- 灵宠行动顺序根据速度属性参与行动条

**多人组队战斗时**:
- 灵宠不直接参战
- 灵宠的**20%属性附加给所属玩家角色**
- 计算方式: 角色最终属性 = 角色原属性 + 灵宠属性 × 20%
- 附加的属性包括: 攻击力、防御力、生命值、速度
- 高级属性（暴击、格挡等）不附加

**属性附加示例**:
```
角色攻击力: 5000
灵宠攻击力: 2000
组队战斗时角色实际攻击力 = 5000 + 2000×20% = 5400
```

#### 2. 灵宠AI行为

灵宠在战斗中的行为由AI自动控制：

**行动优先级**:
1. 若主角生命值<30%，优先使用治疗/保护类功法
2. 若自身有增益类功法且未激活，优先释放增益
3. 正常情况下按1→2→3→4号槽顺序循环释放攻击功法
4. 功法冷却中则跳过，检查下一个槽位

**目标选择**:
- 攻击类功法: 攻击角色对位的敌方单位（跟随主目标）
- 治疗类功法: 优先治疗主角
- 增益类功法: 对自身或主角施放

### 四、灵宠养成

#### 1. 灵宠获取

| 获取途径 | 说明 | 概率 |
|---------|------|------|
| 野外捕捉 | 在特定场景捕捉野生灵兽 | 凡品~上品 |
| 商城购买 | 使用灵石/灵晶购买灵宠蛋 | 良品~卓品 |
| 活动奖励 | 参与限时活动获得 | 上品~极品 |
| 任务奖励 | 完成特定任务赠送 | 固定品种 |
| 合成进化 | 两只相同灵宠合成 | 品阶+1 |

#### 2. 灵宠升级

**经验获取**:
- 伴随角色战斗自动获得经验（为角色经验的50%）
- 使用"灵宠丹"快速提升经验
- 完成灵宠专属任务

**升级效果**:
- 每升一级: 全属性+1%
- 达到特定等级: 解锁新境界阶段
- 境界提升: 大幅提升属性成长率

#### 3. 灵宠装备

**装备部位**（与角色独立）:
- 灵宠饰品: 1个部位
  - 提供灵宠属性加成
  - 可通过打造或商店获得
  - 稀有度: 凡/良/上/卓/极/仙

**装备强化**:
- 消耗灵石和材料强化
- 强化上限受灵宠品阶限制

### 五、元神系统

> 元神是化神境界解锁的高级系统，相当于角色的分身。

#### 1. 开启条件

| 条件 | 要求 |
|------|------|
| 角色境界 | 达到化神境 |
| 前置任务 | 完成"元神出窍"系列任务 |
| 消耗资源 | 10,000灵石 + 100灵晶 |

#### 2. 元神基础设定

**本质**: 元神是角色将元婴修炼出的第二分身，可以独立战斗和成长。

**特点**:
- 元神拥有独立的境界、属性、资质、功法和装备
- 元神境界**不需要突破机制**，只需消耗资源即可升级
- 元神境界**不可超越本体**（角色）
- 元神的加点路线可与本体不同
- 元神可装配角色已获得的功法

#### 3. 元神境界体系

元神采用与角色相同的9大境界体系：

| 元神境界 | 所需灵气 | 所需灵石 | 解锁内容 |
|---------|---------|---------|---------|
| 炼气境 | 1,000 | 500 | 基础形态 |
| 筑基境 | 5,000 | 2,000 | 新外观 |
| 金丹境 | 25,000 | 8,000 | 第3个功法槽 |
| 元婴境 | 100,000 | 30,000 | 第4个功法槽 |
| 化神境 | 400,000 | 100,000 | 全功能解锁 |
| 炼虚境 | 1,600,000 | 300,000 | 特殊光环 |
| 合体境 | 6,400,000 | 800,000 | 独立外观定制 |
| 大乘境 | 25,600,000 | 2,000,000 | 顶级形态 |
| 渡劫境 | 102,400,000 | 5,000,000 | 至尊形态 |

**升级规则**:
- **无突破机制**: 灵气和灵石满足即可直接升级
- **小境界升级**: 消耗灵气，获得5点自由资质点
- **大境界升级**: 消耗更多灵气+灵石，所有资质点+10
- **境界上限锁定**: 元神最高境界 = 本体当前大境界

**示例**:
```
本体: 化神境·五层
→ 元神最高可升至: 化神境·九层（不可进入炼虚境）

本体突破至炼虚境·一层
→ 元神可继续升级至: 炼虚境·九层
```

#### 4. 元神属性与加点

**属性体系**: 与角色完全一致（攻防血速 + 高级属性）

**资质点分配**:
- 元神有独立的资质点
- 加点路线可与本体完全不同
- 示例:
  - 本体走纯攻击路线（全加攻击资质）
  - 元神可以走肉盾路线（全加防御/血量资质）
  - 或走速度流（全加速度资质）

**属性计算公式**（与角色一致）:
```
元神攻击力 = 攻击资质 × (元神基础攻击 + 元神装备攻击) × 攻击系数(1.0)
// 其他属性同理
```

#### 5. 元神功法系统

**功法来源**:
- 元神不能独立学习新功法
- 只能从**角色已经获得的功法**中选择装配
- 角色获得的任何功法，元神都可以使用

**功法槽数量**: 与角色一致，共4个槽位

**装配规则**:
- 元神与角色可装配同一功法（不冲突）
- 元神的功法等级与角色共享（角色升级功法，元神也升级）
- 元神可以在4个槽位间自由切换已获得的功法

**示例**:
```
角色已获功法: 七星剑阵、天罡护体、疾风步、聚灵诀、烈焰掌
→ 元神可从中选择4个装配

角色装配: [七星剑阵][天罡护体][疾风步][聚灵诀]
元神装配: [烈焰掌][天罡护体][聚灵诀][疾风步]
→ 两者可重复使用同一功法
```

#### 6. 元神装备系统

**独立装备**: 元神需要单独佩戴装备

**装备部位**: 与角色一致的6个部位
- 武器、上衣、下装、鞋子、首饰（左）、首饰（右）

**装备获取**:
- 元神装备通过"元神锻造"系统制作
- 消耗材料 + 灵石 + 灵晶
- 元神装备无法与角色通用
- 元神装备的属性成长率略低于角色同级装备（约80%）

**装备强化**: 与角色装备强化机制一致

#### 7. 元神战斗机制

**单人战斗时**:
```
我方阵容（最多5个位置）:
位置4 ┌─────┐
位置2 │ 灵宠 │ ← 灵宠在2号位
位置1 │ 角色 │ ← 角色在1号位
位置3 │ 元神 │ ← 元神在3号位
位置5 │      │
```

- 元神出战时占据**3号位**
- 元神自动释放功法，遵循行动条回合制
- 元神行动顺序根据其速度属性计算

**多人组队战斗时**:
- 元神不直接参战
- 元神的**20%属性附加给所属玩家角色**
- 计算方式与灵宠相同: 角色最终属性 = 角色原属性 + 元神属性 × 20%

**同时拥有灵宠和元神时的组队加成**:
```
单人战斗: 角色(1号) + 灵宠(2号) + 元神(3号)
多人组队: 
  角色属性 = 原属性 + 灵宠属性×20% + 元神属性×20%
```

### 六、界面设计参考

#### 灵宠界面入口
- 主界面中央区域显示灵宠形象（有出战灵宠时）
- 点击灵宠形象进入灵宠详情
- 底部导航栏无单独灵宠入口（在角色/储物中管理）

#### 元神界面入口
- 角色达到化神境后在角色界面显示"元神"标签页
- 点击头像打开角色界面时可切换查看元神信息

## 与其他模块的关联

- **角色系统**: 灵宠/元神绑定角色，属性受角色境界限制
- **战斗系统**: 灵宠占2号位、元神占3号位，组队时属性附加
- **功法系统**: 元神复用角色已获功法，灵宠有独立功法
- **经济系统**: 灵宠/元神养成消耗灵石和灵晶
- **装备系统**: 元神需独立装备，灵宠有饰品部位
