# 社交系统设计文档

## 模块概述

本模块定义游戏中的社交玩法，统称为"仙缘系统"，包含宗门、好友、道侣、结义四大子系统。

## 核心内容

### 一、宗门系统

#### 1. 宗门创建与加入

**创建宗门**:
- 条件: 角色达到筑基期 + 消耗10,000灵石
- 限制: 每个角色只能创建/加入一个宗门
- 命名: 2-6个中文字符，不可重复

**加入宗门**:
- 方式一: 申请加入（需宗主/副宗主审批）
- 方式二: 接受邀请（无需审批）
- 退出宗门: 申请后24小时生效（防止临阵脱逃）

#### 2. 宗门职位

| 职位 | 数量限制 | 权限 |
|------|---------|------|
| 宗主 | 1人 | 全部权限 |
| 副宗主 | 2人 | 除解散宗门外全部权限 |
| 长老 | 5人 | 审批成员、发布任务 |
| 内门弟子 | 无限制 | 参与宗门活动、学习内门技能 |
| 外门弟子 | 无限制 | 基础功能、参与日常活动 |

#### 3. 宗门贡献

**获取途径**:
- 完成宗门每日任务
- 参与宗门副本
- 向宗门捐献灵石/材料
- 参与宗门建设活动

**用途**:
- 在宗门商店兑换道具
- 学习宗门专属技能
- 提升职位等级（需满足贡献+战力要求）

#### 4. 宗门商店

**商品类型**:
- 宗门专属功法残卷
- 特殊炼丹材料
- 稀有装备图纸
- 属性加成丹药

**刷新机制**: 每周一0点刷新

### 二、好友系统

#### 1. 添加好友

**添加方式**:
- 搜索玩家ID/角色名添加
- 附近玩家一键添加
- 战斗后添加对手
- 宗门成员快捷添加

**好友上限**:
- 默认上限: 50人
- 可通过VIP或成就扩展至100人

#### 2. 好友分组

**默认分组**:
- 最近联系
- 宗门好友
- 道侣/结义
- 黑名单

**自定义分组**: 玩家可创建最多5个自定义分组

#### 3. 好友互动

| 功能 | 说明 |
|------|------|
| 赠送礼物 | 可赠送部分道具给好友 |
| 查看信息 | 查看好友的境界、装备、功法等 |
| 私聊 | 一对一文字聊天 |
| 切磋 | 发起友好战斗，无惩罚 |
| 互赠体力 | 每日可赠送/领取体力 |

#### 4. 亲密度系统

**亲密度获取**:
- 每日聊天: +2（上限20）
- 赠送礼物: 根据礼物价值
- 组队挑战: +5/次
- 切磋战斗: +3/次

**亲密度等级**:

| 等级 | 称呼 | 所需亲密度 | 解锁功能 |
|------|------|-----------|---------|
| 1 | 初识 | 0 | 基础聊天 |
| 2 | 熟人 | 100 | 查看装备 |
| 3 | 挚友 | 500 | 互赠稀有道具 |
| 4 | 金兰 | 2000 | 结义前置条件 |
| 5 | 生死之交 | 10000 | 特殊称号 |

### 三、道侣系统

#### 1. 道侣结定

**结定条件**:
- 双方亲密度达到500以上
- 双方均达到金丹期及以上
- 其中一方发起求婚，另一方同意

**结定仪式**:
- 选择婚礼场景（简朴/隆重）
- 发放请帖给好友/宗门成员
- 收到祝福可获得奖励
- 完成仪式获得"XX之道侣"称号

#### 2. 道侣特权

| 特权 | 说明 |
|------|------|
| 灵气加成 | 与道侣组队修炼时，灵气获取速度+5% |
| 战斗加成 | 与道侣组队时，全属性+3% |
| 专属称号 | 显示双方道侣关系 |
| 道侣空间 | 共享一个私密空间 |
| 道侣任务 | 每日完成可获得额外奖励 |

#### 3. 道侣解除

**解除方式**:
- 单方申请解除: 冷却期7天，期间对方可见
- 双方协商解除: 立即生效
- **解除后果**: 
  - 失去所有道侣特权
  - 亲密度清零
  - 30天内不得与同一人重新结定

### 四、结义系统

#### 1. 结义条件

**基本条件**:
- 2-4人同时在线
- 每人亲密度达到2000（金兰）以上
- 所有参与者均达到元婴期及以上
- 消耗每人1000灵晶作为结义费用

**结义流程**:
- 发起者创建结义房间
- 邀请符合条件的玩家加入
- 所有成员确认后进行结义仪式
- 设定结义名号（如"桃园四兄弟"）

#### 2. 结义特权

| 特权 | 说明 |
|------|------|
| 结义加成 | 结义成员组队时，经验+5% |
| 结义称号 | 统一的结义名号显示 |
| 结义仓库 | 共享的小型仓库（50格）|
| 复仇机制 | 任一成员被击败，其他成员可发起复仇挑战 |

#### 3. 结义解除

**解除方式**:
- 单方退出: 需要全员投票（超过半数同意即可）
- 全员解散: 宗主级别操作，立即解散
- **解除后果**:
  - 失去结义特权
  - 结义仓库物品按贡献分配
  - 不可逆操作

## 与其他模块的关联

- **角色系统**: 社交关系影响属性加成
- **战斗系统**: 宗门战、好友切磋、结义合击技
- **经济系统**: 宗门贡献、礼物赠送、道侣/结义费用
- **UI界面**: 统一在"仙缘"导航页展示
