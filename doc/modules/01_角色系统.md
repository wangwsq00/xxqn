# 角色系统设计文档

## 模块概述

本模块定义玩家角色的核心属性、修为体系、境界突破、灵气获取、聚灵阵等核心玩法。

## 核心内容

### 角色基础信息

- **年龄**：根据玩家修炼时长直接增加
- **境界**：决定角色成长和能力上限

### 角色属性分类

#### 基础属性（战斗相关）
- 生命值
- 攻击力
- 防御力
- 速度

#### 高级属性（战斗相关）

##### 暴击属性组
| 属性 | 说明 |
|------|------|
| 暴击率 | 攻击方属性 |
| 抗暴击率 | 防御方属性 |
| **实际暴击率** | = 暴击率 - 抗暴击率，范围0-100 |
| **暴击伤害** | 暴击造成1.5倍伤害 |

##### 格挡属性组
| 属性 | 说明 |
|------|------|
| 格挡率 | 防御方属性 |
| 抗格挡率 | 攻击方属性 |
| **实际格挡率** | = 格挡率 - 抗格挡率，范围0-100 |
| **格挡效果** | 格挡成功时，伤害减少50% |

##### 命中属性组
| 属性 | 说明 |
|------|------|
| 命中率 | 攻击方属性 |
| 闪避率 | 防御方属性 |
| **实际命中率** | 范围30-100（最低保证30%） |

### 灵气值系统（经验值体系）

灵气值作为角色的核心成长资源。

#### 基本规则
- **获取方式**：通过挂机、战斗等途径获得灵气值
- **获取速度**：根据境界不同有不同的基础获取速度
- **灵气有上限**：当前境界小境界升级所需灵气的100%
- **灵气达到上限**：自动触发小境界升级，灵气清零

#### 灵气获取速度

不同境界有不同的基础灵气获取速度：

| 大境界 | 基础灵气/秒 | 相对倍率 |
|--------|-------------|----------|
| 炼气境 | 1 | 1.0x |
| 筑基境 | 2 | 2.0x |
| 金丹境 | 4 | 4.0x |
| 元婴境 | 8 | 8.0x |
| 化神境 | 16 | 16x |
| 炼虚境 | 32 | 32x |
| 合体境 | 64 | 64x |
| 大乘境 | 128 | 128x |
| 渡劫境 | 256 | 256x |

**灵气获取公式**：
```
实际灵气获取速度 = 基础灵气/秒 × (1 + 聚灵阵加成)
```

#### 大境界突破机制

当小境界升至9层时，进入大境界突破阶段。

**突破条件**：
- 灵气达到当前境界所需灵气的100%以上（可挑战心魔）
- 灵气上限为当前境界所需灵气的200%

**灵气积累阶段**：

| 灵气阶段 | 灵气要求 | 可执行操作 |
|----------|----------|------------|
| 积累期 | 0% - 99% | 继续挂机积累灵气 |
| 可挑战期 | 100% - 149% | 可挑战心魔，成功率50% |
| 强化期 | 150% - 199% | 挑战心魔成功率55% |
| 最佳期 | 200% | 挑战心魔成功率60%，灵气上限封顶 |

**突破流程**：
```
1. 灵气积累到100%以上后，可选择挑战心魔
2. 根据当前灵气值确定突破成功率：
   - 100%-149%：基础成功率 50%
   - 150%-199%：成功率 +5% = 55%
   - 200%：成功率 +10% = 60%
3. 挑战心魔后，不管成功与否：
   - 扣除100%灵气值
   - 成功：突破到下一大境界，灵气清零
   - 失败：保留剩余灵气，可继续积累后再次挑战
```

**突破成功奖励**：
- 进入下一大境界1层
- 所有资质点自动+10

**突破失败处理**：
- 灵气扣除100%
- 例如：灵气150%时挑战失败，剩余50%灵气
- 可以继续挂机积累，再次挑战

### 资质系统

#### 资质类型
- 攻击资质
- 防御资质
- 血量资质
- 速度资质

#### 资质点获取规则
- **小境界升级**：每升一个小境界，获得5点自由资质点
- **大境界升级**：每升一个大境界，所有资质点自动加10

#### 基础属性数值设定

- **初始值**：攻防血速基础值均为100
- **境界加成**：每提升一个大境界，基础属性增加50

| 属性类型 | 初始值 | 境界加成 |
|----------|--------|----------|
| 生命值   | 100    | +50/大境界 |
| 攻击力   | 100    | +50/大境界 |
| 防御力   | 100    | +50/大境界 |
| 速度     | 100    | +50/大境界 |

#### 属性计算公式

```
攻击力 = 攻击资质 × (角色基础攻击力 + 装备攻击力) × 攻击系数(1.0)
防御力 = 防御资质 × (角色基础防御力 + 装备防御力) × 防御系数(0.8)
生命值 = 血量资质 × (角色基础血量 + 装备血量) × 生命系数(3.0)
速度   = 速度资质 × (角色基础速度 + 装备速度) × 速度系数(0.5)
```

**公式说明**：
- 角色基础攻击力 = 100 + (当前大境界数 - 1) × 50
- 例如：炼气境基础攻击力 = 100，筑基境基础攻击力 = 150，金丹境基础攻击力 = 200

### 修为与境界体系

#### 境界层级
每个大境界分为9个小境界，例如：金丹境三层

#### 境界列表（从低到高）
1. 炼气境（1-9层）
2. 筑基境（1-9层）
3. 金丹境（1-9层）
4. 元婴境（1-9层）
5. 化神境（1-9层）
6. 炼虚境（1-9层）
7. 合体境（1-9层）
8. 大乘境（1-9层）
9. 渡劫境（1-9层）

### 境界突破机制

#### 小境界升级
- **升级方式**：消耗对应灵气值，自动升级
- **无需条件**：灵气足够即可自动升级
- **升级效果**：境界+1层，消耗对应灵气，获得5资质点

#### 大境界突破
- **突破方式**：需要挑战心魔
- **基础成功率**：50%
- **失败惩罚**：灵气清零（需重新积累）
- **突破成功奖励**：所有资质点+10

#### 突破丹药系统
使用对应层级的突破丹药可提高成功率：

| 丹药等级 | 成功率加成 | 适用境界 |
|----------|------------|----------|
| 下品丹药 | +10%       | 筑基/金丹/元婴 |
| 中品丹药 | +20%       | 筑基/金丹/元婴 |
| 上品丹药 | +30%       | 筑基/金丹/元婴 |
| 极品丹药 | +40%       | 筑基/金丹/元婴 |

**丹药命名规则**：
- 炼气→筑基：筑基丹（下品/中品/上品/极品）
- 筑基→金丹：金丹丹（下品/中品/上品/极品）
- 金丹→元婴：元婴丹（下品/中品/上品/极品）
- 以此类推...
- 高阶境界（化神、炼虚、合体、大乘、渡劫）可使用对应境界的突破丹药

**成功概率示例**：
- 基础突破：50%
- 使用极品丹药：50% + 40% = 90%
- 仍有10%失败风险

## 与其他模块的关联

- 挂机系统：挂机修炼增加灵气值
- 经济系统：聚灵阵升级需要灵石
- 功法系统：功法影响角色属性，通过品级合成提升
- 灵宠系统：灵宠协同战斗
- 战斗系统：角色属性决定战斗表现
