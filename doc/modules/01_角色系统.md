# 角色系统设计文档

## 模块概述

本模块定义玩家角色的核心属性、修为体系、境界突破、灵气获取、聚灵阵、炼体系统等核心玩法。

## 核心内容

### 角色基础信息

- **年龄**：根据玩家修炼时长直接增加
- **境界**：决定角色成长和能力上限

### 角色属性分类

#### 基础属性（战斗相关）
- 生命值
- 攻击力
- 防御力
- 速度

#### 高级属性（战斗相关）

##### 暴击属性组
| 属性 | 说明 |
|------|------|
| 暴击率 | 攻击方属性 |
| 抗暴击率 | 防御方属性 |
| **实际暴击率** | = 暴击率 - 抗暴击率，范围0-100 |
| **暴击伤害** | 暴击造成1.5倍伤害 |

##### 格挡属性组
| 属性 | 说明 |
|------|------|
| 格挡率 | 防御方属性 |
| 抗格挡率 | 攻击方属性 |
| **实际格挡率** | = 格挡率 - 抗格挡率，范围0-100 |
| **格挡效果** | 格挡成功时，伤害减少50% |

##### 命中属性组
| 属性 | 说明 |
|------|------|
| 命中率 | 攻击方属性 |
| 闪避率 | 防御方属性 |
| **实际命中率** | 范围30-100（最低保证30%） |

### 灵气值系统（经验值体系）

灵气值作为角色的核心成长资源，类似于梦幻西游的经验值机制。

#### 基本规则
- **获取方式**：通过挂机、战斗等途径获得灵气值
- **获取速度**：根据境界不同有不同的基础获取速度
- **存在上限**：每个境界有对应的灵气值上限，达到上限后无法继续获得
- **溢出保护**：灵气值达到上限后，不会继续累积

#### 灵气获取速度

不同境界有不同的基础灵气获取速度：

| 大境界 | 基础灵气/秒 | 相对倍率 |
|--------|-------------|----------|
| 炼气境 | 1 | 1.0x |
| 筑基境 | 2 | 2.0x |
| 金丹境 | 4 | 4.0x |
| 元婴境 | 8 | 8.0x |
| 化神境 | 16 | 16x |
| 炼虚境 | 32 | 32x |
| 合体境 | 64 | 64x |
| 大乘境 | 128 | 128x |
| 渡劫境 | 256 | 256x |

**灵气获取公式**：
```
实际灵气获取速度 = 基础灵气/秒 × (1 + 聚灵阵加成)
```

### 炼体系统

炼体是独立于资质的另一套升级体系，消耗灵气直接提升角色的基础属性和高级属性。

#### 炼体等级

炼体等级有独立的升级体系，与境界无关。

| 21-30级 | 炼体后期 |

#### 炼体属性加成

炼体直接提升基础属性和高级属性，而不是资质。

**炼体加点方案**：

| 加点类型 | 消耗点数 | 效果 |
|----------|----------|------|
| 生命加点 | 1点 | 生命上限 +100 |
| 攻击加点 | 1点 | 攻击力 +50 |
| 防御加点 | 1点 | 防御力 +50 |
| 速度加点 | 1点 | 速度 +30 |
| 暴击加点 | 2点 | 暴击率 +5% |
| 抗暴加点 | 2点 | 抗暴击率 +5% |
| 格挡加点 | 2点 | 格挡率 +5% |
| 抗格挡加点 | 2点 | 抗格挡率 +5% |
| 命中加点 | 2点 | 命中率 +5% |
| 闪避加点 | 2点 | 闪避率 +5% |

#### 炼体计算公式

```
最终属性 = 基础属性 + 炼体属性加成 + 资质属性加成 + 装备属性加成

// 其中：
// 基础属性 = 初始值 + 境界加成
// 炼体属性加成 = 炼体各加点类型的累计加成
// 资质属性加成 = 资质计算后的属性
// 装备属性加成 = 装备提供的属性
```

### 资质系统

#### 资质类型
- 攻击资质
- 防御资质
- 血量资质
- 速度资质

#### 资质点获取规则
- **小境界升级**：每升一个小境界，获得5点自由资质点
- **大境界升级**：每升一个大境界，所有资质点自动加10

#### 基础属性数值设定

- **初始值**：攻防血速基础值均为100
- **境界加成**：每提升一个大境界，基础属性增加50

| 属性类型 | 初始值 | 境界加成 |
|----------|--------|----------|
| 生命值   | 100    | +50/大境界 |
| 攻击力   | 100    | +50/大境界 |
| 防御力   | 100    | +50/大境界 |
| 速度     | 100    | +50/大境界 |

#### 属性计算公式

```
攻击力 = 攻击资质 × (角色基础攻击力 + 装备攻击力) × 攻击系数(1.0)
防御力 = 防御资质 × (角色基础防御力 + 装备防御力) × 防御系数(0.8)
生命值 = 血量资质 × (角色基础血量 + 装备血量) × 生命系数(3.0)
速度   = 速度资质 × (角色基础速度 + 装备速度) × 速度系数(0.5)
```

**公式说明**：
- 角色基础攻击力 = 100 + (当前大境界数 - 1) × 50
- 例如：炼气境基础攻击力 = 100，筑基境基础攻击力 = 150，金丹境基础攻击力 = 200

### 修为与境界体系

#### 境界层级
每个大境界分为9个小境界，例如：金丹境三层

#### 境界列表（从低到高）
1. 炼气境（1-9层）
2. 筑基境（1-9层）
3. 金丹境（1-9层）
4. 元婴境（1-9层）
5. 化神境（1-9层）
6. 炼虚境（1-9层）
7. 合体境（1-9层）
8. 大乘境（1-9层）
9. 渡劫境（1-9层）

### 境界突破机制

#### 小境界突破
- **突破方式**：灵气值达到上限后，点击突破按钮直接突破
- **无需条件**：小境界之间可以直接升级
- **突破效果**：境界+1层，灵气值清零，获得5资质点 + 1炼体点

#### 大境界突破
- **突破方式**：需要挑战心魔
- **基础成功率**：50%
- **失败惩罚**：灵气值清零（需重新积累）
- **突破成功奖励**：所有资质点+10，获得10炼体点

#### 突破丹药系统
使用对应层级的突破丹药可提高成功率：

| 丹药等级 | 成功率加成 | 适用境界 |
|----------|------------|----------|
| 下品丹药 | +10%       | 筑基/金丹/元婴 |
| 中品丹药 | +20%       | 筑基/金丹/元婴 |
| 上品丹药 | +30%       | 筑基/金丹/元婴 |
| 极品丹药 | +40%       | 筑基/金丹/元婴 |

**丹药命名规则**：
- 炼气→筑基：筑基丹（下品/中品/上品/极品）
- 筑基→金丹：金丹丹（下品/中品/上品/极品）
- 金丹→元婴：元婴丹（下品/中品/上品/极品）
- 以此类推...
- 高阶境界（化神、炼虚、合体、大乘、渡劫）可使用对应境界的突破丹药

**成功概率示例**：
- 基础突破：50%
- 使用极品丹药：50% + 40% = 90%
- 仍有10%失败风险

## 与其他模块的关联

- 挂机系统：挂机修炼增加灵气值
- 经济系统：聚灵阵升级需要灵石
- 功法系统：功法影响角色属性，通过品级合成提升
- 灵宠系统：灵宠协同战斗
- 战斗系统：角色属性决定战斗表现
