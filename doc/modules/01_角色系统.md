# 角色系统设计文档

## 模块概述

本模块定义玩家角色的核心属性、修为体系、境界突破、灵气获取、聚灵阵等核心玩法。

## 核心内容

### 角色基础信息

- **年龄**：根据玩家修炼时长直接增加
- **境界**：决定角色成长和能力上限

### 角色属性分类

#### 基础属性（战斗相关）
- 生命值
- 攻击力
- 防御力
- 速度

#### 高级属性（战斗相关）

##### 暴击属性组
| 属性 | 说明 |
|------|------|
| 暴击率 | 攻击方属性 |
| 抗暴击率 | 防御方属性 |
| **实际暴击率** | = 暴击率 - 抗暴击率，范围0-100 |
| **暴击伤害** | 暴击造成1.5倍伤害 |

##### 格挡属性组
| 属性 | 说明 |
|------|------|
| 格挡率 | 防御方属性 |
| 抗格挡率 | 攻击方属性 |
| **实际格挡率** | = 格挡率 - 抗格挡率，范围0-100 |
| **格挡效果** | 格挡成功时，伤害减少50% |

##### 命中属性组
| 属性 | 说明 |
|------|------|
| 命中率 | 攻击方属性 |
| 闪避率 | 防御方属性 |
| **实际命中率** | 范围30-100（最低保证30%） |

### 灵气值系统（经验值体系）

灵气值作为角色的核心成长资源。

#### 基本规则
- **获取方式**：通过挂机、战斗等途径获得灵气值
- **获取速度**：根据境界不同有不同的基础获取速度
- **灵气有上限**：当前境界小境界升级所需灵气的100%
- **灵气达到上限**：自动触发小境界升级，灵气清零

#### 灵气获取速度

不同境界有不同的基础灵气获取速度：

| 大境界 | 基础灵气/秒 | 相对倍率 |
|--------|-------------|----------|
| 炼气境 | 1 | 1.0x |
| 筑基境 | 2 | 2.0x |
| 金丹境 | 4 | 4.0x |
| 元婴境 | 8 | 8.0x |
| 化神境 | 16 | 16x |
| 炼虚境 | 32 | 32x |
| 合体境 | 64 | 64x |
| 大乘境 | 128 | 128x |
| 渡劫境 | 256 | 256x |

**灵气获取公式**：
```
实际灵气获取速度 = 基础灵气/秒 × (1 + 聚灵阵加成)
```

#### 聚灵阵系统

玩家可以通过购买和升级聚灵阵来提升灵气获取速度。

**聚灵阵等级与加成**：

| 聚灵阵等级 | 灵气加成 | 购买价格 |
|------------|----------|----------|
| 1级 | +10% | 100灵石 |
| 2级 | +20% | 500灵石 |
| 3级 | +30% | 2,000灵石 |
| 4级 | +40% | 8,000灵石 |
| 5级 | +50% | 30,000灵石 |
| 6级 | +60% | 100,000灵石 |
| 7级 | +70% | 300,000灵石 |
| 8级 | +80% | 800,000灵石 |
| 9级 | +90% | 2,000,000灵石 |
| 10级 | +100% | 5,000,000灵石 |

**聚灵阵升级规则**：
- 从1级开始，每次升级需要消耗灵石
- 最高10级
- 聚灵阵等级影响所有灵气获取途径

#### 小境界升级机制

- **升级条件**：灵气达到当前境界所需的100%
- **升级效果**：自动升级到下一小境界，灵气清零，获得5资质点
- **灵气上限**：当前境界升级所需灵气值

#### 灵气消耗公式

**基础设定**：
- 炼气境1→2层需要灵气 = 100

**灵气增长公式**：

| 升级类型 | 公式 | 说明 |
|----------|------|------|
| 小境界升级 | 当前境界所需灵气 = 上一个小境界所需灵气 × 1.2 | 炼气境2→3层 = 100 × 1.2 = 120 |
| 大境界升级 | 新大境界1→2层所需灵气 = 上一个大境界8→9层所需灵气 × 2 | 筑基境1→2层 = 炼气境8→9层所需灵气 × 2 |

**公式示例**：

```
// 小境界连续升级
炼气境1→2层: 100
炼气境2→3层: 100 × 1.2 = 120
炼气境3→4层: 120 × 1.2 = 144
...

// 大境界切换
炼气境8→9层: X
筑基境1→2层: X × 2
```

#### 大境界突破机制

当小境界升至9层时，进入大境界突破阶段。

**突破条件**：
- 灵气达到当前境界所需灵气的100%以上（可挑战心魔）
- 灵气上限为当前境界所需灵气的200%

**灵气积累阶段**：

| 灵气阶段 | 灵气要求 | 可执行操作 |
|----------|----------|------------|
| 积累期 | 0% - 99% | 继续挂机积累灵气 |
| 可挑战期 | 100% - 200% | 可挑战心魔战斗副本 |

**突破流程**：
```
第一阶段：挑战心魔
1. 灵气积累到100%以上后，可挑战心魔战斗副本
2. 心魔战斗需要玩家具备足够战斗力
3. 战斗失败：无法突破，需要提升功法、装备后重试
4. 战斗胜利：完成突破前置条件，灵气不扣除

第二阶段：突破境界
1. 战胜心魔后，可选择时机进行突破
2. 计算突破成功率：
   - 基础成功率 = 50%
   - 灵气加成：
     * 100%-149%：+0%
     * 150%-199%：+5%
     * 200%：+10%
   - 丹药加成：可选使用丹药提升成功率
3. 突破时扣除100%灵气值
4. 突破结果：
   - 成功：进入下一大境界1层，所有资质点+10，灵气清零
   - 失败：保留剩余灵气（如150%失败→剩50%），可继续积累后再次突破
```

**突破丹药系统**：

使用对应层级的突破丹药可提高成功率：

| 丹药等级 | 成功率加成 | 适用境界 |
|----------|------------|----------|
| 下品丹药 | +10% | 筑基/金丹/元婴 |
| 中品丹药 | +20% | 筑基/金丹/元婴 |
| 上品丹药 | +30% | 筑基/金丹/元婴 |
| 极品丹药 | +40% | 筑基/金丹/元婴 |

**丹药命名规则**：
- 炼气→筑基：筑基丹（下品/中品/上品/极品）
- 筑基→金丹：金丹丹（下品/中品/上品/极品）
- 金丹→元婴：元婴丹（下品/中品/上品/极品）
- 以此类推...
- 高阶境界（化神、炼虚、合体、大乘、渡劫）可使用对应境界的突破丹药

**成功率示例**：
- 基础突破：50%
- 灵气150%+下品丹药：50% + 5% + 10% = 65%
- 灵气200%+极品丹药：50% + 10% + 40% = 100%

### 资质系统

#### 资质类型
- 攻击资质
- 防御资质
- 血量资质
- 速度资质

#### 资质点获取规则
- **小境界升级**：每升一个小境界，获得5点自由资质点
- **大境界升级**：每升一个大境界，所有资质点自动+10

#### 基础属性数值设定

- **初始值**：攻防血速基础值均为100
- **境界加成**：每提升一个大境界，基础属性增加50

| 属性类型 | 初始值 | 境界加成 |
|----------|--------|----------|
| 生命值 | 100 | +50/大境界 |
| 攻击力 | 100 | +50/大境界 |
| 防御力 | 100 | +50/大境界 |
| 速度 | 100 | +50/大境界 |

#### 属性计算公式

```
攻击力 = 攻击资质 × (角色基础攻击力 + 装备攻击力) × 攻击系数(1.0)
防御力 = 防御资质 × (角色基础防御力 + 装备防御力) × 防御系数(0.8)
生命值 = 血量资质 × (角色基础血量 + 装备血量) × 生命系数(3.0)
速度 = 速度资质 × (角色基础速度 + 装备速度) × 速度系数(0.5)
```

**公式说明**：
- 角色基础攻击力 = 100 + (当前大境界数 - 1) × 50
- 例如：炼气境基础攻击力 = 100，筑基境基础攻击力 = 150，金丹境基础攻击力 = 200

### 修为与境界体系

#### 境界层级
每个大境界分为9个小境界，例如：金丹境三层

#### 境界列表（从低到高）
1. 炼气境（1-9层）
2. 筑基境（1-9层）
3. 金丹境（1-9层）
4. 元婴境（1-9层）
5. 化神境（1-9层）
6. 炼虚境（1-9层）
7. 合体境（1-9层）
8. 大乘境（1-9层）
9. 渡劫境（1-9层）

### 境界突破机制

#### 小境界升级
- **升级方式**：消耗对应灵气值，自动升级
- **无需条件**：灵气足够即可自动升级
- **升级效果**：境界+1层，消耗对应灵气，获得5资质点

## 与其他模块的关联

- 挂机系统：挂机修炼增加灵气值
- 经济系统：聚灵阵升级需要灵石
- 功法系统：功法影响角色属性，通过品级合成提升
- 灵宠系统：金丹期解锁，灵宠占2号位参战或20%属性附加
- 元神系统：化神期解锁，元神占3号位参战或20%属性附加
- 战斗系统：角色+灵宠+元神共同组成战斗阵容
