# 装备系统设计

## 1. 概述

装备系统是角色战力的重要组成部分，通过收集、强化、升级装备提升角色战斗能力。

## 2. 装备部位

共6个装备部位：

| 序号 | 部位 | 建议属性倾向 | 说明 |
|------|------|------------|------|
| 1 | 武器 | 攻击力、暴击率 | 核心输出部位 |
| 2 | 上衣 | 生命值、防御力 | 防御/血量部位 |
| 3 | 下装 | 生命值、防御力 | 防御/血量部位 |
| 4 | 鞋子 | 速度、闪避率 | 速度/闪避部位 |
| 5 | 首饰（左） | 多种高级属性 | 自由搭配的首饰槽位 |
| 6 | 首饰（右） | 多种高级属性 | 自由搭配的首饰槽位 |

### 2.1 首饰类型

首饰部位不限制具体类型，支持自由搭配：

| 首饰类型 | 主属性 | 副属性 | 说明 |
|---------|--------|--------|------|
| 玉佩 | 命中率 | 暴击率 | 增强命中能力 |
| 护符 | 格挡率 | 抗暴击率 | 增强生存能力 |
| 戒指 | 攻击力 | 生命值 | 攻防兼备 |
| 手镯 | 防御力 | 速度 | 平衡发展 |
| 项链 | 全属性微量加成 | - | 综合提升 |

玩家可根据获得的装备自由搭配两件首饰，无需限制具体类型。

## 3. 武器类型

武器类型多样化，共10种：

| 武器类型 | 特点 | 说明 |
|--------|------|------|
| 剑 | 攻守平衡 | 最经典的修仙武器 |
| 刀 | 攻击优先 | 高伤害，低命中 |
| 枪 | 速度优先 | 高速度，高暴击 |
| 棍 | 群体伤害 | 适合群攻功法 |
| 斧 | 高伤害 | 单体爆发力强 |
| 锤 | 高暴击 | 暴击伤害极高 |
| 幡 | 法术强化 | 增强法术效果 |
| 印 | 控制强大 | 有特殊控制效果 |
| 镜 | 攻守兼备 | 平衡型法器 |
| 铃 | 辅助功能 | 有特殊加成 |

## 5. 装备获取

1. **副本掉落**：通关副本获得装备
2. **商城购买**：使用游戏货币购买
3. **活动奖励**：参与活动获得
4. **制作合成**：收集材料制作

## 6. 装备强化

通过消耗材料提升装备属性，增加角色战力。
