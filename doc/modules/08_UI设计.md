# UI设计文档

## 模块概述

本模块定义游戏的界面设计规范，包括主界面、战斗界面、背包界面等各模块的UI布局和交互设计。

## 设计理念

- **仙侠国风**: 整体采用水墨仙侠风格，配色以天青、朱砂、玄墨为主，营造飘渺出尘的修仙氛围
- **简洁清晰**: 信息层级分明，重要信息突出显示
- **操作便捷**: 核心功能快速触达，减少操作步骤
- **视觉舒适**: 适当的留白和柔和的动画效果

### UI规范

#### 颜色规范

整体采用水墨仙侠风格，以传统中国色为基础，营造飘渺出尘的修仙氛围。

| 颜色类型 | 传统色名 | 色值 | 用途 |
|---------|---------|------|------|
| 主色-天青 | 天青 | #5BA4A4 | 按钮、灵气特效、品牌色，代表灵力与仙气 |
| 辅色-朱砂 | 朱砂 | #C04851 | 强调信息、稀有物品、突破特效，代表丹道与符箓 |
| 点缀-缃色 | 缃色 | #D9B611 | 进度条、货币数值、选中高亮，代表金丹与灵石 |
| 背景-玄墨 | 玄墨 | #1A1A2E | 主要背景色，深沉如夜空 |
| 背景-黛蓝 | 黛蓝 | #16213E | 卡片、弹窗背景，如远山黛色 |
| 背景-雾灰 | 雾灰 | #2A2D3E | 次级面板背景，如晨雾山色 |
| 文字-月白 | 月白 | #E8E8E8 | 标题、重要信息，清冷如月 |
| 文字-素灰 | 素灰 | #A0A4B0 | 次要信息、说明文字 |
| 文字-淡墨 | 淡墨 | #6B7080 | 辅助信息、时间戳 |

| 特效-灵光 | 灵光 | #7FDBCA | 灵气光效、修炼光环，天青的亮色变体 |

**配色说明**:
- 天青为灵力之色，贯穿整个UI，体现修仙本质
- 朱砂为丹道符箓之色，用于强调与警示
- 缃色为金丹灵石之色，用于数值与进度
- 玄墨黛蓝为山夜之色，营造深邃修仙氛围
- 月白素灰为云雾之色，保证文字可读性

- **标题字体**: 24px / 32px / 48px - 中粗

- **小圆角**: 4px

#### 详细设计

##### 1. 顶部状态栏

**位置**: 屏幕最顶部，高度 70px，半透明毛玻璃效果（玄墨80%透明度）

**左侧 - 玩家信息区**:
```
┌──────────┐
│  ○ 头像   │  韩立
│    缃色边框 │  年龄: 300岁
└──────────┘
```
- 头像: 56px × 56px 圆形，缃色描边2px，点击可进入角色详情
- 角色名: 18px，月白文字，中粗字体
- 年龄: 13px，素灰文字，在名字下方
- VIP标识: 如有VIP等级，在头像右下角显示VIP徽章

**右侧 - 资源与系统**:
```
[💎 12,580] [💠 368]  [🔔] [⚙️]
   灵石       灵晶      通知   设置
```
- 灵石: 缃色图标 + 数值，16px，点击进入充值/获取界面
- 灵晶: 天青色图标 + 数值，16px，点击查看获取途径
- 通知图标: 24px，有未读消息时显示红点+数字角标
- 设置图标: 24px，点击进入设置界面
- **扩展**: 向左滑动可展开更多快捷入口（邮件、好友、排行榜等）

##### 2. 境界标签区

**位置**: 角色立绘上方，居中显示

**样式**:
- 装饰性边框: 中国风卷草纹样，天青色线条
- 背景: 半透明黛蓝色（60%透明度），圆角12px
- 文字: "金丹境·初期"，24px，缃色文字，使用书法风格字体
- **动态效果**: 根据当前境界显示不同颜色和特效
  - 炼气-筑基: 白色光晕
  - 金丹-元婴: 天青色光晕
  - 化神-炼虚: 朱砂色光晕
  - 合体-渡劫: 缃色金光

##### 3. 中央区域 - 角色展示

**位置**: 占据屏幕主要空间（状态栏与进度条之间）

**角色立绘**:
- 显示方式: 盘坐打坐姿态（如参考图）
- 尺寸: 高度约350px，宽度自适应
- 动作: 有轻微呼吸动画（模拟修炼状态）
- **境界特效**: 角色周围显示对应境界的灵气光环
  - 光环样式: 同心圆扩散效果，根据境界变化颜色和层数
  - 炼气期: 单层淡白色光环
  - 筑基期: 双层天青色光环
  - 金丹期: 三层天青+缃色光环（如参考图）
  - 元婴及以上: 更复杂的多层光环+粒子效果

**灵宠跟随** (可选):
- 位置: 角色左下角或右下角
- 尺寸: 约60px × 60px
- 显示: 当前出战灵宠的小型形象
- 点击: 进入灵宠详情界面
- 若无出战灵宠则不显示

##### 4. 修炼进度区

**位置**: 角色立绘下方，距离底部导航栏约100px

**进度条**:
```
╭━━━━━━━━━━━━━━ [▶] ━━━━━━━━━━━━━╮
╰━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╯
  ←── 天青色已填充 ──→←── 未填充 ─→
```
- 外框: 中国风装饰边框，铁灰色，圆角8px
- 内部填充: 从天青色到缃色的渐变（表示进度从低到高）
- 高度: 20px
- 中间按钮: 圆形播放/暂停按钮（直径32px）
  - 播放状态: 显示暂停图标（⏸），表示正在修炼
  - 暂停状态: 显示播放图标（▶），表示挂机暂停
  - 点击切换修炼状态

**进度信息**:
- 进度条下方显示: "修炼速度：1500/分钟"
- 字体: 14px，月白文字
- **点击进度条**: 弹出详细灵气面板，显示：
  - 当前灵气值 / 当前小境界所需灵气
  - 大境界突破所需条件
  - 灵气获取速度明细
  - 可用加速道具

##### 5. 快捷功能区

**位置**: 进度条下方，底部导航栏上方

**布局**: 6个按钮横向排列，间距均匀

**按钮样式**:
- 形状: 圆角方形（圆角12px）或中国风云纹形状
- 尺寸: 64px × 64px
- 图标: 28px，月白色
- 文字: 11px，素灰色，在图标下方
- 背景: 黛蓝色半透明（50%透明度）
- 选中/按下: 天青色半透明背景 + 灵光阴影

**功能列表**:

| 序号 | 功能 | 图标 | 说明 |
|------|------|------|------|
| 1 | 挂机修炼 | ⏱️ | 查看/管理离线收益 |
| 2 | 挑战心魔 | 👹 | 大境界突破前置挑战 |
| 3 | 副本入口 | 🏛️ | 进入副本选择界面 |
| 4 | 试炼之地 | ⚔️ | PVP竞技场入口 |
| 5 | 活动中心 | 🎁 | 限时活动、每日任务 |
| 6 | 每日签到 | 📅 | 每日签到奖励 |

**特殊状态提示**:
- 有可领取奖励时: 按钮右上角显示红点
- 心魔挑战解锁时: 按钮有呼吸闪烁效果
- 新活动上线时: 活动按钮有丹火光效

##### 6. 底部导航栏

**位置**: 屏幕最底部，高度 75px

**背景**: 玄墨色，顶部有1px铁灰色分割线

**导航项** (6个):

| 序号 | 名称 | 图标 | 跳转页面 |
|------|------|------|---------|
| 1 | 角色 | 🧑 | 角色属性界面 |
| 2 | 功法 | 📜 | 功法系统界面 |
| 3 | 挑战 | ⚔️ | 战斗/挑战界面（主页默认选中）|
| 4 | 储物 | 🎒 | 背包/仓库界面 |
| 5 | 宗门 | 🏯 | 宗门界面 |
| 6 | 商城 | 💰 | 商城界面 |

**样式**:
- 图标尺寸: 32px
- 文字尺寸: 11px
- 选中状态: 
  - 图标和文字变为缃色
  - 图标放大1.1倍
  - 上方显示选中指示器（短横线，缃色）
  - 整体上移3px
- 未选中状态:
  - 图标和文字为素灰色
  - 正常大小和位置

**消息提示**:
- 背包有新物品时: 储物图标右上角显示红点
- 商城有优惠时: 商城图标右上角显示"HOT"标签
- 宗门有新消息时: 宗门图标右上角显示数字角标

#### 交互设计

##### 动画与特效

**全局动画**:
- **界面切换**: 水墨晕染过渡效果（从中心向外扩散的墨迹效果）
- **按钮点击**: 灵气涟漪扩散（点击位置产生天青色圆环向外扩散）
- **页面进入**: 元素从下往上淡入，带有轻微上浮效果（模拟灵气上升）

**修炼相关**:
- **进度条填充**: 灵气流动效果（天青色光点从左向右流动）
- **境界光环**: 缓慢旋转+呼吸缩放（同心圆以不同速度旋转）
- **突破成功**: 全屏丹火绽放 + 金色粒子喷发 + 屏幕震动
- **突破失败**: 朱砂红色闪烁 + 屏幕轻微抖动 + 灵气消散效果

**导航交互**:
- **选中切换**: 图标缃色光芒渐亮 + 上浮3px + 下方指示器滑入
- **未选中状态**: 素灰色静态显示
- **消息提示**: 红点弹性出现（scale从0到1.2再到1的弹跳）

**弹窗动画**:
- **打开**: 从中心放大淡入（scale 0.8→1.0，opacity 0→1）
- **关闭**: 向中心缩小淡出（scale 1.0→0.8，opacity 1→0）
- **背景遮罩**: 黑色渐变淡入（opacity 0→0.85）

**浮动元素**:
- **灵气球**: 缓慢上下浮动（±5px）+ 逆时针旋转粒子环绕
- **在线奖励**: 到达领取时间时，胶囊发光脉冲（2秒循环）

##### 音效设计

| 场景 | 音效类型 | 说明 |
|------|---------|------|
| 按钮点击 | 轻微"叮"声 | 清脆短促，类似玉石碰撞 |
| 页面切换 | 风铃声 | 微弱的风铃或古筝拨弦 |
| 进度增长 | 灵气流动声 | 细微的水流或气流声 |
| 境界提升 | 仙乐响起 | 古琴或笛子的高音 |
| 突破成功 | 雷鸣+钟声 | 宏大的雷声配合寺庙钟声 |
| 突破失败 | 低沉闷响 | 类似鼓声或低音 |
| 战斗开始 | 战鼓擂动 | 激昂的鼓点 |
| 获得物品 | 金币落地 | 清脆的金石之声 |

##### 触觉反馈

| 操作 | 反馈强度 | 说明 |
|------|---------|------|
| 普通点击 | 轻度 | 短促震动10ms |
| 重要操作 | 中度 | 双击震动20ms |
| 突破成功 | 强度 | 连续震动100ms |
| 战斗伤害 | 变化 | 根据伤害大小调整震动强度 |

### 交互设计原则

1. **即时反馈**: 用户操作后立即给予视觉或音效反馈
2. **操作确认**: 重要操作（如突破境界、消耗大量资源）需要二次确认
3. **状态提示**: 使用toast提示信息，3秒自动消失
4. **加载状态**: 数据加载时显示loading动画
5. **手势支持**: 支持下拉刷新、左右滑动等手势操作
6. **新手引导**: 新功能第一次使用时有引导提示
