# UI设计文档

## 模块概述

本模块定义游戏的界面设计规范，包括主界面、战斗界面、背包界面等各模块的UI布局和交互设计。

## 设计理念

- **仙侠国风**: 整体采用水墨仙侠风格，配色以天青、朱砂、玄墨为主，营造飘渺出尘的修仙氛围
- **简洁清晰**: 信息层级分明，重要信息突出显示
- **操作便捷**: 核心功能快速触达，减少操作步骤
- **视觉舒适**: 适当的留白和柔和的动画效果

### UI规范

#### 颜色规范

整体采用水墨仙侠风格，以传统中国色为基础，营造飘渺出尘的修仙氛围。

| 颜色类型 | 传统色名 | 色值 | 用途 |
|---------|---------|------|------|
| 主色-天青 | 天青 | #5BA4A4 | 按钮、灵气特效、品牌色，代表灵力与仙气 |
| 辅色-朱砂 | 朱砂 | #C04851 | 强调信息、稀有物品、突破特效，代表丹道与符箓 |
| 点缀-缃色 | 缃色 | #D9B611 | 进度条、货币数值、选中高亮，代表金丹与灵石 |
| 背景-玄墨 | 玄墨 | #1A1A2E | 主要背景色，深沉如夜空 |
| 背景-黛蓝 | 黛蓝 | #16213E | 卡片、弹窗背景，如远山黛色 |
| 背景-雾灰 | 雾灰 | #2A2D3E | 次级面板背景，如晨雾山色 |
| 文字-月白 | 月白 | #E8E8E8 | 标题、重要信息，清冷如月 |
| 文字-素灰 | 素灰 | #A0A4B0 | 次要信息、说明文字 |
| 文字-淡墨 | 淡墨 | #6B7080 | 辅助信息、时间戳 |
| 边框-铁灰 | 铁灰 | #3A3D50 | 分割线、边框 |
| 特效-灵光 | 灵光 | #7FDBCA | 灵气光效、修炼光环，天青的亮色变体 |
| 特效-丹火 | 丹火 | #E8634A | 战斗特效、伤害数字，朱砂的亮色变体 |

**配色说明**:
- 天青为灵力之色，贯穿整个UI，体现修仙本质
- 朱砂为丹道符箓之色，用于强调与警示
- 缃色为金丹灵石之色，用于数值与进度
- 玄墨黛蓝为山夜之色，营造深邃修仙氛围
- 月白素灰为云雾之色，保证文字可读性

#### 字体规范

- **标题字体**: 24px / 32px / 48px - 中粗
- **正文字体**: 14px / 16px / 18px - 常规
- **辅助字体**: 12px - 常规

#### 间距规范

- **超小间距**: 4px
- **小间距**: 8px
- **标准间距**: 16px
- **大间距**: 24px
- **超大间距**: 32px

#### 圆角规范

- **小圆角**: 4px
- **标准圆角**: 8px
- **大圆角**: 12px
- **圆形**: 50%

#### 阴影规范

- **轻微阴影**: 0 1px 2px rgba(0,0,0,0.2)
- **标准阴影**: 0 4px 6px rgba(0,0,0,0.3)
- **强化阴影**: 0 10px 15px rgba(0,0,0,0.4)
- **灵光阴影**: 0 0 12px rgba(91,164,164,0.4)，用于灵气、修炼等特效
- **丹火阴影**: 0 0 12px rgba(192,72,81,0.4)，用于战斗、突破等特效

#### 详细设计

##### 1. 顶部状态栏

**位置**: 屏幕最顶部，高度 70px，半透明毛玻璃效果（玄墨80%透明度）

**左侧 - 玩家信息区**:
```
┌──────────┐
│  ○ 头像   │  韩立
│    缃色边框 │  年龄: 300岁
└──────────┘     ↑ 点击进入角色界面
```
- 头像: 56px × 56px 圆形，缃色描边2px，**点击打开角色界面**（角色属性、装备、资质等）
- 角色名: 18px，月白文字，中粗字体
- 年龄: 13px，素灰文字，在名字下方
- VIP标识: 如有VIP等级，在头像右下角显示VIP徽章
- **交互**: 点击头像区域整体响应，有明显按下反馈

**右侧 - 活动入口**:
```
[▼]
活动中心
```
- 图标: 向下箭头/卷轴图标，28px，缃色
- 点击: 展开活动面板
- **收起状态**: 显示"▼"图标 + "活动中心"文字（可配置显示红点）
- **展开状态**: 箭头变为"▲"，下方弹出活动面板

**活动面板详情**:
```
╭━━━━━━━━━━━━━━━━━━━━━━╮
│ ▲ 活动中心             │  ← 点击收起
│ ───────────────────── │
│                         │
│ 🎁 每日签到    [已签]   │  ← 已完成状态
│ 🎊 福利领取    [3项]   │  ← 有可领取时高亮+红点
│ ⏰ 限时活动    [进行中] │  ← 进行中闪烁提示
│ 🎯 七日目标    [3/7天] │  ← 进度显示
│ 📅 月卡奖励    [领取]   │  ← 可领取时缃色按钮
│ 🔥 充值特惠    [查看]   │  ← 新人专享标识
│ ⭐ 成就系统    [新成就] │  ← 有新成就时提示
│                         │
╰━━━━━━━━━━━━━━━━━━━━━━╯
```

- 面板宽度: 260px，从右上角向下展开
- 背景: 黛蓝色（90%透明度），圆角12px，铁灰色边框
- 每行高度: 48px，点击对应区域跳转功能
- **特殊状态**:
  - 有可领取福利: 整行缃色边框发光 + 右侧"[领取]"按钮
  - 新活动上线: 对应行左侧显示"NEW"标签（朱砂色）
  - 即将结束: 倒计时显示，剩余<1小时时红色警告

##### 2. 境界标签区

**位置**: 角色立绘上方，居中显示

**样式**:
- 装饰性边框: 中国风卷草纹样，天青色线条
- 背景: 半透明黛蓝色（60%透明度），圆角12px
- 文字: "金丹境·初期"，24px，缃色文字，使用书法风格字体
- **动态效果**: 根据当前境界显示不同颜色和特效
  - 炼气-筑基: 白色光晕
  - 金丹-元婴: 天青色光晕
  - 化神-炼虚: 朱砂色光晕
  - 合体-渡劫: 缃色金光

##### 3. 中央区域 - 角色展示

**位置**: 占据屏幕主要空间（状态栏与进度条之间）

**角色立绘**:
- 显示方式: 盘坐打坐姿态（如参考图）
- 尺寸: 高度约350px，宽度自适应
- 动作: 有轻微呼吸动画（模拟修炼状态）
- **境界特效**: 角色周围显示对应境界的灵气光环
  - 光环样式: 同心圆扩散效果，根据境界变化颜色和层数
  - 炼气期: 单层淡白色光环
  - 筑基期: 双层天青色光环
  - 金丹期: 三层天青+缃色光环（如参考图）
  - 元婴及以上: 更复杂的多层光环+粒子效果

**灵宠跟随** (可选):
- 位置: 角色左下角或右下角
- 尺寸: 约60px × 60px
- 显示: 当前出战灵宠的小型形象
- 点击: 进入灵宠详情界面
- 若无出战灵宠则不显示

##### 4. 修炼进度与突破区

**位置**: 角色立绘下方，距离底部导航栏约120px

**进度条**:
```
╭━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╮
╰━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╯
  ←── 天青色已填充(75%) ──→←── 未填充 ─→
```
- 外框: 中国风装饰边框，铁灰色，圆角8px
- 内部填充: 从天青色到缃色的渐变（表示进度从低到高）
- 高度: 20px
- **无播放/暂停按钮**: 挂机修炼始终进行中，无需手动控制

**进度信息**:
- 进度条下方显示: "修炼速度：1500/分钟"
- 字体: 14px，月白文字
- **点击进度条**: 弹出详细灵气面板，显示：
  - 当前灵气值 / 当前小境界所需灵气
  - 灵气获取速度明细
  - 可用加速道具
  - 预计升级时间

**突破按钮** (灵气达到100%时出现):
```
╭━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╮
│          🔥 突破境界              │  ← 丹火渐变色背景
╰━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╯
```
- **显示条件**: 当前灵气值 ≥ 小境界所需灵气的100%
- **样式**: 
  - 宽度: 屏幕宽度的70%，居中显示
  - 高度: 48px
  - 背景: 朱砂到缃色的渐变 + 丹火阴影特效
  - 文字: "🔥 突破境界"，18px，月白文字
  - 边框: 缃色描边2px
- **动画**: 
  - 出现时从下往上滑入（带弹性效果）
  - 持续时有呼吸发光脉冲（丹火色光晕循环）
  - 提示用户可以突破了
- **点击**: 打开突破页面（详见布局结构中的突破页面设计）

**突破按钮状态变化**:

| 灵气状态 | 显示 | 说明 |
|---------|------|------|
| <100% | 不显示 | 正常修炼中 |
| =100% | 显示"突破境界" | 可进入突破页面 |
| >100% | 显示"突破境界(+X%)" | 显示额外成功率加成 |

##### 5. 底部导航栏

**位置**: 屏幕最底部，高度 75px

**背景**: 玄墨色，顶部有1px铁灰色分割线

**布局**: 5个按钮均分屏幕宽度，挑战位于正中间

```
┌─────────┬─────────┬─────────┬─────────┬─────────┐
│         │         │         │         │         │
│  [储物]  │  [功法]  │  [挑战]  │  [仙缘]  │  [商行]  │
│         │         │ (稍大)   │         │         │
└─────────┴─────────┴─────────┴─────────┴─────────┘
   图标     图标      图标       图标      图标
   文字     文字      文字       文字      文字
```

**导航项**:

| 序号 | 名称 | 图标 | 跳转页面 | 主要内容 |
|------|------|------|---------|---------|
| 1 | 储物 | 🎒 | 储物界面 | 灵石/灵晶显示、道具背包、装备仓库 |
| 2 | 功法 | 📜 | 功法界面 | 已修炼功法、未获得功法、功法装配 |
| 3 | 挑战 | ⚔️ | 挑战界面 | **副本来表、心魔挑战、PVP竞技场** |
| 4 | 仙缘 | 🤝 | 仙缘界面 | 宗门、好友、道侣、结义系统 |
| 5 | 商行 | 💰 | 商行界面 | 灵石商城、灵晶商城、宗门兑换 |

**样式设计（手机操作优化）**:
- 所有按钮尺寸统一: 图标36px + 文字11px
- **挑战按钮特殊处理**（更显眼）:
  - 图标尺寸: 40px（比其他大12%）
  - 文字大小: 12px
  - 默认颜色: 缃色（其他为素灰色）
  - 背景: 可有微弱的天青色底光效果
- **无选中状态**: 手机操作即点即跳转，无需选中态
- **点击反馈**: 
  - 按下时图标缩小至90%（模拟物理按压）
  - 松开后立即跳转页面
- **消息提示**（角标显示在图标右上角）:
  - 储物有新物品: 红点
  - 商行有优惠/更新: "HOT"标签（朱砂色）
  - 仙缘有新消息: 数字角标
  - 挑战有新副本开放/可突破: 丹火闪烁提示

#### 交互设计

##### 动画与特效

**全局动画**:
- **界面切换**: 水墨晕染过渡效果（从中心向外扩散的墨迹效果）
- **按钮点击**: 灵气涟漪扩散（点击位置产生天青色圆环向外扩散）
- **页面进入**: 元素从下往上淡入，带有轻微上浮效果（模拟灵气上升）

**修炼相关**:
- **进度条填充**: 灵气流动效果（天青色光点从左向右流动）
- **境界光环**: 缓慢旋转+呼吸缩放（同心圆以不同速度旋转）
- **突破成功**: 全屏丹火绽放 + 金色粒子喷发 + 屏幕震动
- **突破失败**: 朱砂红色闪烁 + 屏幕轻微抖动 + 灵气消散效果

**导航交互**:
- **选中切换**: 图标缃色光芒渐亮 + 上浮3px + 下方指示器滑入
- **未选中状态**: 素灰色静态显示
- **消息提示**: 红点弹性出现（scale从0到1.2再到1的弹跳）

**弹窗动画**:
- **打开**: 从中心放大淡入（scale 0.8→1.0，opacity 0→1）
- **关闭**: 向中心缩小淡出（scale 1.0→0.8，opacity 1→0）
- **背景遮罩**: 黑色渐变淡入（opacity 0→0.85）

**浮动元素**:
- **灵气球**: 缓慢上下浮动（±5px）+ 逆时针旋转粒子环绕
- **在线奖励**: 到达领取时间时，胶囊发光脉冲（2秒循环）

##### 音效设计

| 场景 | 音效类型 | 说明 |
|------|---------|------|
| 按钮点击 | 轻微"叮"声 | 清脆短促，类似玉石碰撞 |
| 页面切换 | 风铃声 | 微弱的风铃或古筝拨弦 |
| 进度增长 | 灵气流动声 | 细微的水流或气流声 |
| 境界提升 | 仙乐响起 | 古琴或笛子的高音 |
| 突破成功 | 雷鸣+钟声 | 宏大的雷声配合寺庙钟声 |
| 突破失败 | 低沉闷响 | 类似鼓声或低音 |
| 战斗开始 | 战鼓擂动 | 激昂的鼓点 |
| 获得物品 | 金币落地 | 清脆的金石之声 |

##### 触觉反馈

| 操作 | 反馈强度 | 说明 |
|------|---------|------|
| 普通点击 | 轻度 | 短促震动10ms |
| 重要操作 | 中度 | 双击震动20ms |
| 突破成功 | 强度 | 连续震动100ms |
| 战斗伤害 | 变化 | 根据伤害大小调整震动强度 |

### 交互设计原则

1. **即时反馈**: 用户操作后立即给予视觉或音效反馈
2. **操作确认**: 重要操作（如突破境界、消耗大量资源）需要二次确认
3. **状态提示**: 使用toast提示信息，3秒自动消失
4. **加载状态**: 数据加载时显示loading动画
5. **手势支持**: 支持下拉刷新、左右滑动等手势操作
6. **新手引导**: 新功能第一次使用时有引导提示
