# UI设计文档

## 模块概述

本模块定义游戏的界面设计规范，包括主界面、战斗界面、背包界面等各模块的UI布局和交互设计。

## 设计理念

- **修仙主题**: 整体采用中国风设计，配色以紫、金、黑为主
- **简洁清晰**: 信息层级分明，重要信息突出显示
- **操作便捷**: 核心功能快速触达，减少操作步骤
- **视觉舒适**: 适当的留白和柔和的动画效果

| 背景-深 | #0F172A | 主要背景色 |

### 主界面设计

#### 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│  顶部状态栏  [玩家信息][灵气值][货币信息]  [系统图标]        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                      中央区域                                │
│                                                             │
│              [角色模型 + 境界显示]                           │
│                                                             │
│              [快捷功能按钮组]                                │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  底部导航栏  [角色][功法][灵宠][背包][宗门][商城]            │
└─────────────────────────────────────────────────────────────┘
```

#### 详细设计

##### 1. 顶部状态栏

**位置**: 屏幕最顶部，高度 60px

**左侧 - 玩家信息**:
- 头像: 50px × 50px 圆形，金色边框
- 角色名: 16px，主色文字
- 境界标签: 12px，紫色背景，白色文字，圆角8px
- 年龄: 12px，次要文字，在名字下方

**中间 - 灵气与进度**:
- 当前境界进度条: 高度10px，圆角5px
- 进度文字: "7500 / 10000"，14px
- 灵气获取速度: "+10/秒"，金色文字，12px

**右侧 - 货币与系统**:
- 灵石: 图标 + 数值，16px
- 灵晶: 图标 + 数值，16px
- 系统图标区: 设置、通知、邮件，每个24px

##### 2. 中央区域

**位置**: 状态栏与导航栏之间，占据主要空间

**上半部分 - 角色展示**:
- 角色立绘/模型: 居中显示，高度300px
- 境界特效: 根据当前境界显示对应的光环效果
- 灵宠跟随: 可选，在角色旁显示当前出战灵宠

**下半部分 - 快捷功能**:
- 6个圆形按钮，2行3列布局
- 按钮尺寸: 80px × 80px，带图标和文字
- 功能包括:
  - 挂机修炼
  - 挑战心魔
  - 副本入口
  - 试炼之地
  - 活动中心
  - 每日签到

##### 3. 底部导航栏

**位置**: 屏幕最底部，高度70px

**导航项** (6个):
- [角色] - 跳转角色属性界面
- [功法] - 跳转功法系统界面
- [灵宠] - 跳转灵宠系统界面
- [背包] - 跳转背包/仓库界面
- [宗门] - 跳转宗门界面
- [商城] - 跳转商城界面

**样式**:
- 每个图标40px，文字12px
- 选中状态: 图标和文字变为金色，有上移效果
- 未选中: 灰色显示

##### 4. 快捷浮窗

**灵气球**: 悬浮在右下角，圆形60px，可快速查看灵气详情

#### 交互设计

- **点击效果**: 所有可点击元素有明显的按下反馈
- **跳转动画**: 界面切换使用淡入淡出+缩放效果
- **进度动画**: 灵气值增长有平滑的动画效果
- **境界突破**: 有全屏特效和音效

### 交互设计原则

1. **即时反馈**: 用户操作后立即给予视觉或音效反馈
2. **操作确认**: 重要操作（如突破境界、消耗大量资源）需要二次确认
3. **状态提示**: 使用toast提示信息，3秒自动消失
4. **加载状态**: 数据加载时显示loading动画
5. **手势支持**: 支持下拉刷新、左右滑动等手势操作
6. **新手引导**: 新功能第一次使用时有引导提示
