# 经济系统设计文档

## 模块概述

本模块定义游戏中的虚拟货币、资源体系、交易系统等经济相关机制。

## 核心内容

### 货币体系

#### 1. 灵石（普通游戏货币）

**定位**: 游戏内基础流通货币，玩家日常消耗的主要货币

**获取途径**:
| 途径 | 说明 | 频率 |
|------|------|------|
| 挂机收益 | 离线/在线挂机自动产出 | 持续 |
| 副本掉落 | 通过战斗副本获得 | 每日有限次 |
| 任务奖励 | 完成主线/支线/每日任务获得 | 每日刷新 |
| 出售物品 | 在商店出售不需要的装备/材料 | 随时 |
| 签到奖励 | 每日签到获得 | 每日1次 |
| 成就奖励 | 完成成就目标获得 | 一次性 |

**用途**:
| 用途 | 说明 |
|------|------|
| 购买普通道具 | 药材、材料、低级装备等 |
| 强化装备 | 装备升级、洗炼等操作 |
| 功法升级 | 消耗灵石提升功法等级 |
| 灵宠培养 | 灵宠喂养、进阶等 |
| 商城购买 | 灵石商城中的普通商品 |
| 其他消耗 | 修理费用、传送费用等 |

**初始值**: 新角色创建时给予1000灵石
**上限**: 无上限（或设置较大上限如99,999,999）

#### 2. 灵晶（付费货币）

**定位**: 稀有付费货币，用于购买珍稀道具和享受特殊服务

**获取途径**:
| 途径 | 说明 | 备注 |
|------|------|------|
| 充值购买 | 使用真实货币充值获得 | 主要来源 |
| 月卡/周卡 | 购买月卡每日领取灵晶 | 性价比高 |
| 限时活动 | 参与特定活动获得 | 数量有限 |
| 成就达成 | 完成特殊成就奖励 | 少量 |
| 首充奖励 | 首次充值赠送额外灵晶 | 一次性 |
| 充值返利 | 累计充值达到额度返还 | 长期活动 |

**充值档位建议**:
| 档位 | 价格 | 获得灵晶 | 首充双倍 |
|------|------|---------|---------|
| 小型 | ¥6 | 60 | ✅ |
| 中型 | ¥30 | 300 | ✅ |
| 大型 | ¥98 | 980 | ✅ |
| 豪华 | ¥198 | 1980 | ✅ |
| 至尊 | ¥328 | 3280+300(赠) | ✅ |

**用途**（灵晶专属）:
| 用途 | 说明 |
|------|------|
| 珍稀道具 | 高级丹药、稀有材料、特殊道具 |
| 外观装扮 | 时装、坐骑、头像框、称号等 |
| 加速修炼 | 购买加速道具快速获取灵气 |
| 扩展功能 | 扩大背包格子、解锁额外功能位 |
| 抽卡/寻宝 | 概率性获取高级物品 |
| 复活续命 | 战斗中复活或延长挑战次数 |
| VIP特权 | 解锁VIP等级特权 |

**与灵石的兑换**: 不支持直接兑换，保持两种货币的独立性

#### 3. 宗门贡献（社交货币）

**定位**: 宗门内部流通货币，用于宗门相关消费

**获取途径**:
- 宗门任务: 完成宗门发布的任务
- 宗门副本: 参与宗门集体副本
- 宗门捐献: 向宗门捐献资源
- 宗门活动: 宗门战、宗门建设等活动

**用途**:
- 宗门商店购买特殊道具
- 学习宗门专属技能
- 提升宗门职位等级
- 宗门建设贡献

### 交易系统

#### 商城系统

**灵石商城**:
- 刷新时间: 每日0点刷新
- 商品类型: 普通道具、材料、低级装备
- 价格范围: 几百到几万灵石
- 限量商品: 部分热门商品每日限购

**灵晶商城**:
- 刷新时间: 部分商品限时上架
- 商品类型: 珍稀道具、外观装扮、礼包
- 价格范围: 几十到几千灵晶
- 限定商品: 节日活动、版本限定

**宗门商店**:
- 刷新时间: 每周一刷新
- 商品类型: 宗门专属道具、特殊材料
- 价格: 宗门贡献 + 灵石/灵晶混合支付

#### 玩家交易

**暂不支持**: 第一版暂不开放玩家间直接交易，避免工作室刷金问题

#### 回收系统

**商店回收**:
- 玩家可向系统商店出售不需要的物品
- 回收价格为物品价值的固定比例（如50%）
- 支持批量出售

**分解系统**:
- 不需要的装备可分解为材料
- 分解产物可用于打造新装备

### 经济平衡设计

#### 产出控制

| 途径 | 日均产出灵石 | 说明 |
|------|------------|------|
| 挂机收益 | ~5000 | 与角色等级相关 |
| 副本奖励 | ~2000-5000 | 根据副本难度 |
| 任务完成 | ~3000 | 主线+支线+每日 |
| **合计** | **~10000-13000** | 普通玩家日均 |

#### 消耗引导

| 消耗类型 | 日均消耗灵石 | 占比 |
|---------|------------|------|
| 装备强化 | ~3000 | 25% |
| 功法升级 | ~2000 | 17% |
| 药品购买 | ~1500 | 13% |
| 其他消耗 | ~5500 | 45% |

#### 通货膨胀控制

- 设置灵石硬上限或软上限
- 定期推出消耗活动回收灵石
- 高级消费主要引导至灵晶
- 防止工作室：限制每日交易/出售总额

## 与其他模块的关联

- **挂机系统**: 挂机产出灵石和灵气
- **功法系统**: 功法升级消耗灵石和灵晶
- **灵宠系统**: 灵宠培养消耗资源和货币
- **战斗系统**: 战斗奖励产出资源
- **社交系统**: 宗门贡献、宗门商店
- **装备系统**: 装备强化/打造消耗大量灵石
