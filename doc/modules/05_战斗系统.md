# 战斗系统设计文档

## 模块概述

本模块定义游戏中的战斗机制，包括副本挑战、PVP对战、自动战斗等。

## 核心内容

### 战斗模式

- 单人战斗
- 多人副本
- PVP竞技
- 公会战

### 战斗机制

#### 阵容设置

- **上阵单位**：攻守双方最多各5个单位
- **位置布局**：从上到下位置号为 4 - 2 - 1 - 3 - 5，1号位在中间

```
位置布局示意图：
    4号位
    2号位
    1号位（中间）
    3号位
    5号位
```

#### 我方阵容配置规则

**单人战斗时的阵容**:

| 位置 | 单位 | 条件 | 说明 |
|------|------|------|------|
| 1号位 | 玩家角色 | 始终存在 | 主目标位置 |
| 2号位 | 出战灵宠 | 角色达到金丹期且拥有灵宠 | AI自动控制 |
| 3号位 | 元神 | 角色达到化神期且已解锁元神 | AI自动控制 |
| 4号位 | 空 | - | 预留 |
| 5号位 | 空 | - | 预留 |

- 灵宠和元神各自独立参与行动条，根据自身速度行动
- 灵宠/元神的功法释放遵循各自的功法槽顺序（1→2→3→4→普攻）

**多人组队战斗时的阵容**:

| 位置 | 单位 | 说明 |
|------|------|------|
| 1号位 | 玩家角色（属性含灵宠+元神加成） | 主目标位置 |
| 2-5号位 | 其他队友 | 每人占据一个位置 |

**组队时属性附加计算**:
```
最终攻击力 = 角色原攻击力 
           + (灵宠攻击力 × 20%，如有出战灵宠)
           + (元神攻击力 × 20%，如已解锁元神)

最终防御力 = 角色原防御力 + 灵宠防御力×20% + 元神防御力×20%
最终生命值 = 角色原生命值 + 灵宠生命值×20% + 元神生命值×20%
最终速度   = 角色原速度   + 灵宠速度×20%   + 元神速度×20%

// 高级属性（暴击率、格挡率、命中率、闪避率）不附加
```

**示例**:
```
玩家A（有灵宠+元神）组队挑战:
- 角色攻击: 5000, 灵宠攻击: 2000, 元神攻击: 3000
- 组队实际攻击 = 5000 + 2000×0.2 + 3000×0.2 = 5000 + 400 + 600 = 6000

玩家B（无灵宠无元神）组队挑战:
- 角色攻击: 5500
- 组队实际攻击 = 5500（无加成）
```

#### 行动条回合制

所有存活的参战单位在同一个行动条上移动：
1. 单位的速度属性决定行动条移动速度
2. 先到达终点的单位发起行动
3. 行动完成后，重置自己在行动条上的位置
4. 循环往复，直到一方全部阵亡

#### 目标选择机制

**主目标优先级**：
1. 首先选择对位单位（1号对1号，2号对2号...）
2. 如果对位单位不可攻击（阵亡、隐身等），按1-5号顺序寻找下一个存活的敌人作为主目标

**目标选择流程**：
```
主目标 = 对位单位
如果 主目标不可攻击：
    遍历1-5号位，找到第一个存活的单位作为主目标
```

#### 功法选择与释放

**功法槽顺序**：
1. 1号功法（优先）
2. 2号功法（次优先）
3. 3号功法（第三）
4. 4号功法（第四）
5. 普通攻击（保底）

**释放流程**：
```
对于行动单位：
    遍历1-4号功法槽：
        如果 功法已装备 AND 功法冷却结束 AND 未被禁止施法：
            使用该功法
            进入技能释放和伤害计算
            功法冷却开始倒计时
            返回
    // 所有功法槽都不可释放，使用普通攻击
    使用普通攻击
    进入伤害计算
    返回
```

**无法释放情况**：
- 功法未装备
- 功法冷却中
- 单位被禁止施法

#### 攻击方式

根据功法设计，攻击方式分为三种：

| 攻击类型 | 描述 | 适用场景 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 普通攻击、单体技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

**普通攻击**：仅单体攻击

### 伤害计算

#### 普通攻击 vs 功法攻击

| 攻击类型 | 功法系数 | 伤害段数 |
|----------|----------|----------|
| 普通攻击 | 100% | 1段 |
| 功法攻击 | 功法定义 | 功法定义 |

#### 伤害计算流程

伤害计算按照以下顺序进行判定：

```
1. 目标选择
2. 命中判定
3. 暴击判定
4. 格挡判定
5. 最终伤害计算
```

#### 1. 命中判定

```
实际命中率 = max(30, 攻击方命中率 - 防御方闪避率)
命中判定 = random(0-100) < 实际命中率

如果未命中：不造成伤害，结束
```

#### 2. 暴击判定

```
实际暴击率 = 攻击方暴击率 - 防御方抗暴击率
实际暴击率 = clamp(实际暴击率, 0, 100)

暴击判定 = random(0-100) < 实际暴击率
暴击伤害系数 = 1.5（暴击时）
```

#### 3. 格挡判定

```
实际格挡率 = 防御方格挡率 - 攻击方抗格挡率
实际格挡率 = clamp(实际格挡率, 0, 100)

格挡判定 = random(0-100) < 实际格挡率
格挡减伤系数 = 0.5（格挡时）
```

#### 4. 基础伤害计算

```
基础伤害 = max(攻击力 - 防御力, 1)
```

#### 5. 完整伤害公式（普通攻击）

```
// 输入参数
攻击方：攻击力、命中率、暴击率、抗格挡率
防御方：防御力、闪避率、抗暴击率、格挡率

// 计算过程
1. 实际命中率 = clamp(命中率 - 闪避率, 30, 100)
2. 实际暴击率 = clamp(暴击率 - 抗暴击率, 0, 100)
3. 实际格挡率 = clamp(格挡率 - 抗格挡率, 0, 100)

4. 如果 random(100) >= 实际命中率：
     伤害 = 0（未命中）

5. 如果 random(100) < 实际暴击率：
     暴击系数 = 1.5
   否则：
     暴击系数 = 1.0

6. 如果 random(100) < 实际格挡率：
     格挡系数 = 0.5
   否则：
     格挡系数 = 1.0

7. 最终伤害 = max(攻击力 - 防御力, 1) × 暴击系数 × 格挡系数
```

#### 6. 功法攻击伤害计算

功法攻击在基础伤害上乘以功法伤害系数，并且支持多段伤害。

**单段伤害功法**：
```
最终伤害 = 基础伤害 × 功法伤害系数 × 暴击系数 × 格挡系数
```

**多段伤害功法**：
每段伤害单独计算命中、暴击、格挡，并且可能有触发中断机制。

**伤害结果输出格式**：
```
伤害结果 = [
    {
        段数: 1,
        触发状态: "命中" | "未命中" | "未触发",
        暴击状态: true | false,
        格挡状态: true | false,
        伤害值: 数字,
        累计伤害: 数字
    },
    {
        段数: 2,
        触发状态: "命中" | "未命中" | "未触发",
        暴击状态: true | false,
        格挡状态: true | false,
        伤害值: 数字,
        累计伤害: 数字
    },
    ...
]
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 段数 | number | 第几段伤害 |
| 触发状态 | string | "命中"=造成伤害，"未命中"=被闪避，"未触发"=中断未触发 |
| 暴击状态 | boolean | true=暴击 |
| 格挡状态 | boolean | true=被格挡 |
| 伤害值 | number | 本段伤害数值（未命中或未触发时为0） |
| 累计伤害 | number | 到本段为止的总伤害 |

**计算逻辑**：
```
伤害结果 = []
累计伤害 = 0
触发了前一段 = true

for (段数 from 1 to 功法总段数) {
    本段结果 = {
        段数: 段数,
        触发状态: "未触发",
        暴击状态: false,
        格挡状态: false,
        伤害值: 0,
        累计伤害: 累计伤害
    }
    
    if (触发了前一段) {
        // 检查本段是否触发中断
        if (本段有触发概率要求) {
            if (random(100) >= 触发概率) {
                伤害结果.push(本段结果)
                break  // 中断，后面不再触发
            }
        }
        
        // 计算本段伤害
        实际命中率 = clamp(命中率 - 闪避率, 30, 100)
        
        if (random(100) < 实际命中率) {
            暴击 = random(100) < 实际暴击率
            格挡 = random(100) < 实际格挡率
            
            暴击系数 = 暴击 ? 1.5 : 1.0
            格挡系数 = 格挡 ? 0.5 : 1.0
            
            本段伤害 = max(攻击力 - 防御力, 1) × 功法本段伤害系数 × 暴击系数 × 格挡系数
            累计伤害 += 本段伤害
            
            本段结果.触发状态 = "命中"
            本段结果.暴击状态 = 暴击
            本段结果.格挡状态 = 格挡
            本段结果.伤害值 = 本段伤害
            本段结果.累计伤害 = 累计伤害
        } else {
            本段结果.触发状态 = "未命中"
            本段结果.累计伤害 = 累计伤害
        }
        
        触发了前一段 = true
    }
    
    伤害结果.push(本段结果)
}

return 伤害结果
```

**界面展示要求**：
- 根据伤害结果数组，依次播放每段伤害动画
- 每段伤害动画需要显示：
  - 伤害数字飘字
  - 暴击时显示暴击特效和数字放大
  - 格挡时显示格挡特效和减伤提示
  - 未命中时显示闪避提示
- 每段伤害之间可以有短暂延迟（如200-300ms），让玩家看清每段伤害
- 累计伤害可以显示在界面上

#### 伤害计算示例 - 普通攻击

**场景**：攻击方 vs 防御方

| 属性 | 攻击方 | 防御方 |
|------|--------|--------|
| 攻击力 | 10,000 | - |
| 防御力 | - | 8,000 |
| 命中率 | 80 | - |
| 闪避率 | - | 30 |
| 暴击率 | 20 | - |
| 抗暴击率 | - | 10 |
| 格挡率 | - | 15 |
| 抗格挡率 | 5 | - |

**计算过程**：
1. 实际命中率 = max(30, 80 - 30) = 50
2. 实际暴击率 = 20 - 10 = 10
3. 实际格挡率 = 15 - 5 = 10
4. 基础伤害 = 10,000 - 8,000 = 2,000

**假设情况**：
- 命中 + 暴击 + 格挡：2,000 × 1.5 × 0.5 = 1,500
- 命中 + 暴击 + 未格挡：2,000 × 1.5 = 3,000
- 命中 + 未暴击 + 格挡：2,000 × 0.5 = 1,000
- 命中 + 未暴击 + 未格挡：2,000
- 未命中：0

#### 伤害计算示例 - 七星剑阵

**场景**：攻击方使用七星剑阵 vs 防御方（同上方属性）

**七星剑阵伤害段数**：

| 段数 | 伤害系数 | 触发概率 | 说明 |
|------|----------|----------|------|
| 第1剑 | 30% | 100% | 必定触发 |
| 第2剑 | 40% | 100% | 必定触发 |
| 第3剑 | 50% | 70% | 中断则后面不触发 |
| 第4剑 | 60% | 70% | 中断则后面不触发 |
| 第5剑 | 70% | 70% | 中断则后面不触发 |
| 第6剑 | 80% | 70% | 中断则后面不触发 |
| 第7剑 | 100% | 70% | 中断则后面不触发 |

**七星剑阵计算过程**：

```
总伤害 = 0
触发了前一段 = true

// 第1剑（30%，100%触发）
if (random(100) < 50) {
    暴击系数 = (random(100) < 10) ? 1.5 : 1.0
    格挡系数 = (random(100) < 10) ? 0.5 : 1.0
    本段伤害 = 2000 × 0.3 × 暴击系数 × 格挡系数
    总伤害 += 本段伤害
}
触发了前一段 = true

// 第2剑（40%，100%触发）
if (random(100) < 50) {
    暴击系数 = (random(100) < 10) ? 1.5 : 1.0
    格挡系数 = (random(100) < 10) ? 0.5 : 1.0
    本段伤害 = 2000 × 0.4 × 暴击系数 × 格挡系数
    总伤害 += 本段伤害
}
触发了前一段 = true

// 第3-7剑（50%-100%，70%触发，可能中断）
for (段数 from 3 to 7) {
    if (random(100) >= 70) {
        break  // 中断
    }
    
    if (random(100) < 50) {
        暴击系数 = (random(100) < 10) ? 1.5 : 1.0
        格挡系数 = (random(100) < 10) ? 0.5 : 1.0
        功法系数 = [0.5, 0.6, 0.7, 0.8, 1.0][段数-3]
        本段伤害 = 2000 × 功法系数 × 暴击系数 × 格挡系数
        总伤害 += 本段伤害
    }
}

return 总伤害
```

**七星剑阵期望伤害示例**（假设所有命中、无暴击无格挡）：
- 理想情况（7剑全中）：2000×(0.3+0.4+0.5+0.6+0.7+0.8+1.0) = 2000×4.3 = **8,600**
- 典型情况（出5剑）：2000×(0.3+0.4+0.5+0.6+0.7) = 2000×2.5 = **5,000**

### 战斗胜负判定

#### 判定条件

战斗结束按以下优先级判定：

| 优先级 | 条件 | 结果 |
|--------|------|------|
| 1 | 攻击方单位全部阵亡 | 攻击方失败，防守方胜利 |
| 2 | 防守方单位全部阵亡 | 防守方失败，攻击方胜利 |
| 3 | 攻击方回合数超过50回合 | 攻击方失败，防守方胜利 |

#### 回合计数规则

- 每当攻击方单位发起行动，回合数+1
- 防守方行动不计入回合数
- 回合数在战斗界面显示，便于玩家观察战况

#### 超时判定示例

```
战斗进行中...
第48回合: 攻击方灵宠行动
第49回合: 攻击方角色行动
第50回合: 攻击方元神行动 ← 回合数=50
第51回合: 攻击方角色行动 ← 回合数=51，超过50，判定防守方胜利
```

### 心魔挑战

#### 设计理念

心魔挑战是验证玩家综合实力的考验，目的是**挡住只提升境界而忽视功法和装备的玩家**。

#### 设计原则

1. **战力门槛**: 怪物属性远超当前境界的基础属性
2. **考验全面**: 敌人配置考验输出、生存、控制多方面能力
3. **可重复挑战**: 失败后可继续提升后重试，无惩罚

#### 心魔配置

心魔模拟一个"完美状态的目标境界玩家"，使用该境界的标准装备和标准功法。

**心魔设计基准**:

| 配置项 | 数值 | 说明 |
|--------|------|------|
| 基础属性 | 目标境界基础值 | 以目标境界的大境界基础属性为基准（如突破筑基→金丹，心魔基础属性=金丹境基础值）|
| 装备 | 当前境界普通装备 | 穿戴该境界的普通装备（非极品，非稀有）|
| 功法 | 当前境界普通功法 | 装配1-2个该境界可获得的普通功法 |
| 资质点 | 均衡分配 | 攻防血速平均分配 |

**境界基础属性参考**:

| 境界 | 基础攻击 | 基础防御 | 基础生命 | 基础速度 |
|------|---------|---------|---------|---------|
| 炼气境 | 100 | 100 | 100 | 100 |
| 筑基境 | 150 | 150 | 150 | 150 |
| 金丹境 | 200 | 200 | 200 | 200 |
| 元婴境 | 250 | 250 | 250 | 250 |
| 化神境 | 300 | 300 | 300 | 300 |
| 炼虚境 | 350 | 350 | 350 | 350 |
| 合体境 | 400 | 400 | 400 | 400 |
| 大乘境 | 450 | 450 | 450 | 450 |
| 渡劫境 | 500 | 500 | 500 | 500 |

**心魔难度示例**:

| 挑战 | 心魔定位 | 装备 | 功法 | 难度 |
|------|---------|------|------|------|
| 炼气→筑基 | 筑基境玩家 | 筑基普通装备 | 无 | 简单 |
| 筑基→金丹 | 金丹境玩家 | 金丹普通装备 | 1个黄级功法 | 中等 |
| 金丹→元婴 | 元婴境玩家 | 元婴普通装备 | 1-2个玄级功法 | 较难 |
| 元婴→化神 | 化神境玩家 | 化神普通装备 | 2个地级功法 | 困难 |
| 化神→炼虚 | 炼虚境玩家 | 炼虚普通装备 | 2-3个天级功法 | 极难 |

**设计说明**:

- 心魔的装备和功法是"标准水平"，而非极品
- 玩家若有更好装备/功法，打心魔会相对轻松
- 玩家若只有境界而装备/功法差，则难以通过
- 这样确保了"境界提升必须同步提升装备和功法"的设计目标

#### 心魔功法配置

| 境界 | 心魔功法 | 效果 |
|------|---------|------|
| 炼气 | 普通攻击 | 纯普攻 |
| 筑基 | 【破甲一击】 | 降低防御30%，持续2回合 |
| 金丹 | 【自愈】+单体攻击 | 每回合回复10%最大生命 |
| 元婴 | 【灭魂斩】+【护体】 | 高伤害+护盾 |
| 化神+ | 【多段攻击】+【控制】 | 全套功法组合 |

#### 挑战流程

```
1. 玩家满足挑战条件（灵气≥100%）
2. 进入心魔战斗界面
3. 战斗开始
4. 战胜 → 心魔状态标记"已完成"，可进行境界突破
5. 战败 → 可继续挑战，无额外惩罚
```

#### 失败惩罚

**无惩罚**: 心魔挑战失败不会扣除灵气或道具，玩家可以立即重试。

> 心魔的存在确保玩家在追求境界提升的同时，必须兼顾功法和装备的成长。

### PVP竞技场（论道台）

#### 竞技规则

| 项目 | 规则 |
|------|------|
| 挑战方式 | 对排名前10名的玩家发起挑战 |
| 挑战胜利 | 与对手互换排名 |
| 挑战失败 | 排名不变 |
| 每日次数 | 5次/天（可消耗灵晶购买额外次数）|
| 每日奖励 | 每天21:00根据排名发放 |

#### 排名规则

- 初始排名: 所有玩家按境界和战力排序
- 排名显示: 显示前100名玩家（仅显示境界和名称）
- 匹配机制: 可查看排名前10的玩家，选择挑战

#### 每日奖励

| 排名区间 | 灵石奖励 | 灵晶奖励 | 其他 |
|----------|---------|---------|------|
| 第1名 | 10,000 | 50 | 专属称号 |
| 第2-5名 | 5,000 | 30 | 高级称号 |
| 第6-10名 | 3,000 | 20 | 中级称号 |
| 第11-50名 | 1,000 | 10 | - |
| 第51-100名 | 500 | 5 | - |
| 第100名后 | 100 | 1 | - |

#### 竞技战斗规则

- **战斗类型**: 自动战斗，双方AI控制
- **战斗时长上限**: 50回合（超时判攻击方负）
- **参战单位**: 角色 + 灵宠 + 元神（各自独立行动）
- **禁用道具**: 战斗中不可使用药品等道具
- **允许使用功法**: 双方可正常使用装配的功法

### 战斗奖励

战斗奖励根据副本类型和通关情况发放。

#### 奖励计算公式

**灵石奖励**:
```
灵石奖励 = 基础灵石 × (1 + 境界加成系数)

境界加成系数:
- 炼气境: 1.0
- 筑基境: 1.5
- 金丹境: 2.0
- 元婴境: 3.0
- 化神境: 4.0
- 炼虚境+: 5.0
```

**材料掉落**:
```
掉落判定 = random(100)

剧情副本:
- 掉落率: 30%
- 掉落物品: 炼丹材料 或 炼器材料

精英副本:
- 掉落率: 80%
- 掉落物品: 珍稀材料（根据副本类型）
```

#### 奖励发放

| 副本类型 | 灵石 | 炼丹材料 | 炼器材料 | 其他 |
|----------|------|---------|---------|------|
| 剧情副本 | ✅ | ✅(概率) | ✅(概率) | 首次通关额外奖励 |
| 日常副本 | ✅ | ✅ | ✅ | 灵气丹、丹药、装备(概率) |
| 精英副本 | ✅(较多) | ✅(珍稀) | ✅(珍稀) | 功法残卷(概率) |
| 心魔挑战 | ❌ | ❌ | ❌ | 无奖励，仅解锁突破 |
| PVP竞技 | ❌ | ❌ | ❌ | 无战斗奖励，仅排名奖励 |

## 与其他模块的关联

- 角色系统：角色属性决定战斗力
- 功法系统：战斗中使用功法，决定攻击方式和伤害
- 灵宠系统：灵宠占2号位参战（单人）或20%属性附加（组队）
- 元神系统：元神占3号位参战（单人）或20%属性附加（组队）
- 经济系统：战斗产出资源
