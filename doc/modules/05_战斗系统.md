# 战斗系统设计文档

## 模块概述

本模块定义游戏中的战斗机制，包括副本挑战、PVP对战、自动战斗等。

## 核心内容

### 战斗模式

- 单人战斗
- 多人副本
- PVP竞技
- 公会战

### 战斗机制

#### 阵容设置

- **上阵单位**：攻守双方最多各5个单位
- **位置布局**：从上到下位置号为 4 - 2 - 1 - 3 - 5，1号位在中间

```
位置布局示意图：
    4号位
    2号位
    1号位（中间）
    3号位
    5号位
```

#### 行动条回合制

所有存活的参战单位在同一个行动条上移动：
1. 单位的速度属性决定行动条移动速度
2. 先到达终点的单位发起行动
3. 行动完成后，重置自己在行动条上的位置
4. 循环往复，直到一方全部阵亡

#### 目标选择机制

**主目标优先级**：
1. 首先选择对位单位（1号对1号，2号对2号...）
2. 如果对位单位不可攻击（阵亡、隐身等），按1-5号顺序寻找下一个存活的敌人作为主目标

**目标选择流程**：
```
主目标 = 对位单位
如果 主目标不可攻击：
    遍历1-5号位，找到第一个存活的单位作为主目标
```

#### 攻击方式

根据功法设计，攻击方式分为三种：

| 攻击类型 | 描述 | 适用场景 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 普通攻击、单体技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

**普通攻击**：仅单体攻击
