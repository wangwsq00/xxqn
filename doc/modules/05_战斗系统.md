# 战斗系统设计文档

## 模块概述

本模块定义游戏中的战斗机制，包括副本挑战、PVP对战、自动战斗等。

## 核心内容

### 战斗模式

- 单人战斗
- 多人副本
- PVP竞技
- 公会战

### 战斗机制

#### 阵容设置

- **上阵单位**：攻守双方最多各5个单位
- **位置布局**：从上到下位置号为 4 - 2 - 1 - 3 - 5，1号位在中间

```
位置布局示意图：
    4号位
    2号位
    1号位（中间）
    3号位
    5号位
```

#### 我方阵容配置规则

**单人战斗时的阵容**:

| 位置 | 单位 | 条件 | 说明 |
|------|------|------|------|
| 1号位 | 玩家角色 | 始终存在 | 主目标位置 |
| 2号位 | 出战灵宠 | 角色达到金丹期且拥有灵宠 | AI自动控制 |
| 3号位 | 元神 | 角色达到化神期且已解锁元神 | AI自动控制 |
| 4号位 | 空 | - | 预留 |
| 5号位 | 空 | - | 预留 |

- 灵宠和元神各自独立参与行动条，根据自身速度行动
- 灵宠/元神的功法释放遵循各自的功法槽顺序（1→2→3→4→普攻）

**多人组队战斗时的阵容**:

| 位置 | 单位 | 说明 |
|------|------|------|
| 1号位 | 玩家角色（属性含灵宠+元神加成） | 主目标位置 |
| 2-5号位 | 其他队友 | 每人占据一个位置 |

**组队时属性附加计算**:
```
最终攻击力 = 角色原攻击力 
           + (灵宠攻击力 × 20%，如有出战灵宠)
           + (元神攻击力 × 20%，如已解锁元神)

最终防御力 = 角色原防御力 + 灵宠防御力×20% + 元神防御力×20%
最终生命值 = 角色原生命值 + 灵宠生命值×20% + 元神生命值×20%
最终速度   = 角色原速度   + 灵宠速度×20%   + 元神速度×20%

// 高级属性（暴击率、格挡率、命中率、闪避率）不附加
```

**示例**:
```
玩家A（有灵宠+元神）组队挑战:
- 角色攻击: 5000, 灵宠攻击: 2000, 元神攻击: 3000
- 组队实际攻击 = 5000 + 2000×0.2 + 3000×0.2 = 5000 + 400 + 600 = 6000

玩家B（无灵宠无元神）组队挑战:
- 角色攻击: 5500
- 组队实际攻击 = 5500（无加成）
```

#### 行动条回合制

所有存活的参战单位在同一个行动条上移动：
1. 单位的速度属性决定行动条移动速度
2. 先到达终点的单位发起行动
3. 行动完成后，重置自己在行动条上的位置
4. 循环往复，直到一方全部阵亡

#### 目标选择机制

**主目标优先级**：
1. 首先选择对位单位（1号对1号，2号对2号...）
2. 如果对位单位不可攻击（阵亡、隐身等），按1-5号顺序寻找下一个存活的敌人作为主目标

**目标选择流程**：
```
主目标 = 对位单位
如果 主目标不可攻击：
    遍历1-5号位，找到第一个存活的单位作为主目标
```

#### 功法选择与释放

**功法槽顺序**：
1. 1号功法（优先）
2. 2号功法（次优先）
3. 3号功法（第三）
4. 4号功法（第四）
5. 普通攻击（保底）

**释放流程**：
```
对于行动单位：
    遍历1-4号功法槽：
        如果 功法已装备 AND 功法冷却结束 AND 未被禁止施法：
            使用该功法
            进入技能释放和伤害计算
            功法冷却开始倒计时
            返回
    // 所有功法槽都不可释放，使用普通攻击
    使用普通攻击
    进入伤害计算
    返回
```

**无法释放情况**：
- 功法未装备
- 功法冷却中
- 单位被禁止施法

#### 攻击方式

根据功法设计，攻击方式分为三种：

| 攻击类型 | 描述 | 适用场景 |
|----------|------|----------|
| 单体攻击 | 只攻击主目标 | 普通攻击、单体技能 |
| 群体攻击 | 攻击所有敌人 | 范围伤害技能 |
| 随机3人 | 攻击主目标 + 另外随机2人 | 多目标技能 |

**普通攻击**：仅单体攻击

### 伤害计算

#### 普通攻击 vs 功法攻击

| 攻击类型 | 功法系数 | 伤害段数 |
|----------|----------|----------|
| 普通攻击 | 100% | 1段 |
| 功法攻击 | 功法定义 | 功法定义 |

#### 伤害计算流程

伤害计算按照以下顺序进行判定：

```
1. 目标选择
2. 命中判定
3. 暴击判定
4. 格挡判定
5. 最终伤害计算
```

#### 1. 命中判定

```
实际命中率 = max(30, 攻击方命中率 - 防御方闪避率)
命中判定 = random(0-100) < 实际命中率

如果未命中：不造成伤害，结束
```

#### 2. 暴击判定

```
实际暴击率 = 攻击方暴击率 - 防御方抗暴击率
实际暴击率 = clamp(实际暴击率, 0, 100)

暴击判定 = random(0-100) < 实际暴击率
暴击伤害系数 = 1.5（暴击时）
```

#### 3. 格挡判定

```
实际格挡率 = 防御方格挡率 - 攻击方抗格挡率
实际格挡率 = clamp(实际格挡率, 0, 100)

格挡判定 = random(0-100) < 实际格挡率
格挡减伤系数 = 0.5（格挡时）
```

#### 4. 基础伤害计算

```
基础伤害 = max(攻击力 - 防御力, 1)
```

#### 5. 完整伤害公式（普通攻击）

```
// 输入参数
攻击方：攻击力、命中率、暴击率、抗格挡率
防御方：防御力、闪避率、抗暴击率、格挡率

// 计算过程
1. 实际命中率 = clamp(命中率 - 闪避率, 30, 100)
2. 实际暴击率 = clamp(暴击率 - 抗暴击率, 0, 100)
3. 实际格挡率 = clamp(格挡率 - 抗格挡率, 0, 100)

4. 如果 random(100) >= 实际命中率：
     伤害 = 0（未命中）

5. 如果 random(100) < 实际暴击率：
     暴击系数 = 1.5
   否则：
     暴击系数 = 1.0

6. 如果 random(100) < 实际格挡率：
     格挡系数 = 0.5
   否则：
     格挡系数 = 1.0

7. 最终伤害 = max(攻击力 - 防御力, 1) × 暴击系数 × 格挡系数
```

#### 6. 功法攻击伤害计算

功法攻击在基础伤害上乘以功法伤害系数，并且支持多段伤害。

**单段伤害功法**：
```
最终伤害 = 基础伤害 × 功法伤害系数 × 暴击系数 × 格挡系数
```

**多段伤害功法**：
每段伤害单独计算命中、暴击、格挡，并且可能有触发中断机制。

**伤害结果输出格式**：
```
伤害结果 = [
    {
        段数: 1,
        触发状态: "命中" | "未命中" | "未触发",
        暴击状态: true | false,
        格挡状态: true | false,
        伤害值: 数字,
        累计伤害: 数字
    },
    {
        段数: 2,
        触发状态: "命中" | "未命中" | "未触发",
        暴击状态: true | false,
        格挡状态: true | false,
        伤害值: 数字,
        累计伤害: 数字
    },
    ...
]
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 段数 | number | 第几段伤害 |
| 触发状态 | string | "命中"=造成伤害，"未命中"=被闪避，"未触发"=中断未触发 |
| 暴击状态 | boolean | true=暴击 |
| 格挡状态 | boolean | true=被格挡 |
| 伤害值 | number | 本段伤害数值（未命中或未触发时为0） |
| 累计伤害 | number | 到本段为止的总伤害 |

**计算逻辑**：
```
伤害结果 = []
累计伤害 = 0
触发了前一段 = true

for (段数 from 1 to 功法总段数) {
    本段结果 = {
        段数: 段数,
        触发状态: "未触发",
        暴击状态: false,
        格挡状态: false,
        伤害值: 0,
        累计伤害: 累计伤害
    }
    
    if (触发了前一段) {
        // 检查本段是否触发中断
        if (本段有触发概率要求) {
            if (random(100) >= 触发概率) {
                伤害结果.push(本段结果)
                break  // 中断，后面不再触发
            }
        }
        
        // 计算本段伤害
        实际命中率 = clamp(命中率 - 闪避率, 30, 100)
        
        if (random(100) < 实际命中率) {
            暴击 = random(100) < 实际暴击率
            格挡 = random(100) < 实际格挡率
            
            暴击系数 = 暴击 ? 1.5 : 1.0
            格挡系数 = 格挡 ? 0.5 : 1.0
            
            本段伤害 = max(攻击力 - 防御力, 1) × 功法本段伤害系数 × 暴击系数 × 格挡系数
            累计伤害 += 本段伤害
            
            本段结果.触发状态 = "命中"
            本段结果.暴击状态 = 暴击
            本段结果.格挡状态 = 格挡
            本段结果.伤害值 = 本段伤害
            本段结果.累计伤害 = 累计伤害
        } else {
            本段结果.触发状态 = "未命中"
            本段结果.累计伤害 = 累计伤害
        }
        
        触发了前一段 = true
    }
    
    伤害结果.push(本段结果)
}

return 伤害结果
```

**界面展示要求**：
- 根据伤害结果数组，依次播放每段伤害动画
- 每段伤害动画需要显示：
  - 伤害数字飘字
  - 暴击时显示暴击特效和数字放大
  - 格挡时显示格挡特效和减伤提示
  - 未命中时显示闪避提示
- 每段伤害之间可以有短暂延迟（如200-300ms），让玩家看清每段伤害
- 累计伤害可以显示在界面上

#### 伤害计算示例 - 普通攻击

**场景**：攻击方 vs 防御方

| 属性 | 攻击方 | 防御方 |
|------|--------|--------|
| 攻击力 | 10,000 | - |
| 防御力 | - | 8,000 |
| 命中率 | 80 | - |
| 闪避率 | - | 30 |
| 暴击率 | 20 | - |
| 抗暴击率 | - | 10 |
| 格挡率 | - | 15 |
| 抗格挡率 | 5 | - |

**计算过程**：
1. 实际命中率 = max(30, 80 - 30) = 50
2. 实际暴击率 = 20 - 10 = 10
3. 实际格挡率 = 15 - 5 = 10
4. 基础伤害 = 10,000 - 8,000 = 2,000

**假设情况**：
- 命中 + 暴击 + 格挡：2,000 × 1.5 × 0.5 = 1,500
- 命中 + 暴击 + 未格挡：2,000 × 1.5 = 3,000
- 命中 + 未暴击 + 格挡：2,000 × 0.5 = 1,000
- 命中 + 未暴击 + 未格挡：2,000
- 未命中：0

#### 伤害计算示例 - 七星剑阵

**场景**：攻击方使用七星剑阵 vs 防御方（同上方属性）

**七星剑阵伤害段数**：

| 段数 | 伤害系数 | 触发概率 | 说明 |
|------|----------|----------|------|
| 第1剑 | 30% | 100% | 必定触发 |
| 第2剑 | 40% | 100% | 必定触发 |
| 第3剑 | 50% | 70% | 中断则后面不触发 |
| 第4剑 | 60% | 70% | 中断则后面不触发 |
| 第5剑 | 70% | 70% | 中断则后面不触发 |
| 第6剑 | 80% | 70% | 中断则后面不触发 |
| 第7剑 | 100% | 70% | 中断则后面不触发 |

**七星剑阵计算过程**：

```
总伤害 = 0
触发了前一段 = true

// 第1剑（30%，100%触发）
if (random(100) < 50) {
    暴击系数 = (random(100) < 10) ? 1.5 : 1.0
    格挡系数 = (random(100) < 10) ? 0.5 : 1.0
    本段伤害 = 2000 × 0.3 × 暴击系数 × 格挡系数
    总伤害 += 本段伤害
}
触发了前一段 = true

// 第2剑（40%，100%触发）
if (random(100) < 50) {
    暴击系数 = (random(100) < 10) ? 1.5 : 1.0
    格挡系数 = (random(100) < 10) ? 0.5 : 1.0
    本段伤害 = 2000 × 0.4 × 暴击系数 × 格挡系数
    总伤害 += 本段伤害
}
触发了前一段 = true

// 第3-7剑（50%-100%，70%触发，可能中断）
for (段数 from 3 to 7) {
    if (random(100) >= 70) {
        break  // 中断
    }
    
    if (random(100) < 50) {
        暴击系数 = (random(100) < 10) ? 1.5 : 1.0
        格挡系数 = (random(100) < 10) ? 0.5 : 1.0
        功法系数 = [0.5, 0.6, 0.7, 0.8, 1.0][段数-3]
        本段伤害 = 2000 × 功法系数 × 暴击系数 × 格挡系数
        总伤害 += 本段伤害
    }
}

return 总伤害
```

**七星剑阵期望伤害示例**（假设所有命中、无暴击无格挡）：
- 理想情况（7剑全中）：2000×(0.3+0.4+0.5+0.6+0.7+0.8+1.0) = 2000×4.3 = **8,600**
- 典型情况（出5剑）：2000×(0.3+0.4+0.5+0.6+0.7) = 2000×2.5 = **5,000**

## 与其他模块的关联

- 角色系统：角色属性决定战斗力
