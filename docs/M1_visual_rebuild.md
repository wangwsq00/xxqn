# M1 视觉重建

把洞府从黑底表单改成山洞庭院：全幅背景、大立绘、顶栏与底栏。不改玩法、公式、存档结构、入口顺序与跳转、战斗计时 / 伤害 / 行动条，也不改 Pages 部署。

逻辑帧已经是 **720×1280**（`GAME_WIDTH` / `GAME_HEIGHT`），按 1:1 使用下面的尺寸，不再另做缩放。

## 调色

只使用这些颜色：

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨色 | `#1A2A3A` / `#2E4050` | 底、面板、底栏 |
| 宣纸 | `#F3E6C8` | 次级文字 |
| 朱砂 | `#C23B22` | 主按钮、选中底栏、血条 |
| 赤金 | `#C9A227` | 描边、灵石、行动条、金按钮 |
| 青 | `#3AA8A0` | 境界条、我方提示 |
| 勾线 | `#0E1620` | 金按钮上的字、阴影 |
| 正文 | `#FFF8EE` | 标题与正文 |

常量在 `src/ui/theme.ts` 的 `PALETTE`。

## 立绘

键名不变：`player_hero`、`pet_linghu`、`enemy_wild`、`enemy_evil`、`enemy_demon`、`enemy_heart_demon`。战斗与洞府大立绘锚点 `origin(0.5, 1)`。

| 位置 | 显示高度 | 脚底 |
|------|----------|------|
| 洞府主角 | 420（规格 380–440） | `(360, 780)` |
| 洞府灵宠 | 主角的 60%（规格 55–65%） | 主角右后方，层级更低 |
| 战斗主角 | 360（规格 340–400） | 槽位常量 `(150, 452)` |
| 战斗敌人 | 220（规格 200–240） | 敌方列，脚底 Y 用槽位常量 |
| 战斗灵宠 | 220 | 我方 2 号位脚底 Y 不变，画面上向右错开，避免被更高的主角牌完全挡住 |

槽位顺序仍是 **4-2-1-3-5**，主角在我方 1 号中位。`SLOT_FOOT_Y` / `ALLY_SLOT_X` 不改。

现有立绘没有透明通道，所以洞府和战斗用金边立绘牌，而不是抠图精灵。

## 界面控件

仓库里没有 `ui_panel.png` / `ui_btn.png`。按切图规格做 Phaser 等价物，常量同在 `theme.ts`：

- 面板：256 参考，九宫边 32。场景里是墨色圆角矩形 + 赤金描边。
- 按钮：宽 128 的参考，左右内边距 24、上下 20。实际按钮按热区放大，圆角不超过 16。

底栏高 **152**，三项热区高 **120**（≥ 96）。选中为朱砂底 + 赤金描边与金字。

洞府底栏只有 **洞府 / 试炼 / 养成**。聚灵阵、装备、功法、灵宠按这个顺序放进「养成」面板，不再铺在庭院中间。点进去仍是原来的场景。

试炼底栏项进入 `TrialSelect`（原先「进入试炼」）。挑战心魔仍在洞府主按钮旁，条件与提示不变。

## 各屏

- **洞府**：全幅 `bg_dongfu`，大主角；顶栏三枚筹码（境界 / 灵气 / 灵石）和一条境界条；主按钮「领取洞府收益」，没有可领时为「暂无可领」。去掉存档说明和阵容脚注。
- **试炼**：`bg_trial`，海报卡放大敌人立绘，解锁卡只有一个「挑战」。未解锁压暗并加锁。
- **战斗**：`bg_battle` 铺在场地后。血条用朱砂、行动条用赤金，名字压在立绘顶部的墨色牌上。出手、飘字、胜负结算的时序不改。
- **装备 / 功法 / 聚灵阵 / 灵宠**：同一套墨色面板、赤金描边和按钮。玩家看不见 LocalStorage、场景名、原始 id、FPS、TODO 或调试字。

## 动效（只做 P0）

按下立刻缩一下再弹回；养成面板淡入淡出；境界条、血条、行动条用短补间。回调在补间之前同步执行，不推迟领取、跳转或战斗结算。
